# PHP Fatal Error Resolution: Undefined constant "LUPOPEDIA_PATH" in oauth-controller.php

## Error Analysis

**Stack Trace:**
```
PHP Fatal error:  Uncaught Error: Undefined constant "LUPOPEDIA_PATH" in C:\ServBay\www\servbay\lupopedia\lupo-includes\modules\auth\oauth-controller.php:14
Stack trace:
#0 C:\ServBay\www\servbay\lupopedia\lupo-includes\modules\module-loader.php(49): require_once()
#1 C:\ServBay\www\servbay\lupopedia\lupo-includes\lupopedia-loader.php(78): require_once('C:\\ServBay\\www\\...')
#2 C:\ServBay\www\servbay\lupopedia\lupo-includes\bootstrap.php(239): require_once('C:\\ServBay\\www\\...')
#3 C:\ServBay\www\servbay\lupopedia\lupo-includes\modules\auth\oauth-controller.php(14)
```

**Root Cause:**
The `oauth-controller.php` file is trying to use the `LUPOPEDIA_PATH` constant before it's defined. This occurs because the file is loaded by `module-loader.php` before `bootstrap.php` has a chance to define the essential constants.

**File Loading Sequence Issue:**
1. `module-loader.php` loads `oauth-controller.php` (line 49)
2. `oauth-controller.php` tries to use `LUPOPEDIA_PATH` (line 14)
3. `bootstrap.php` defines `LUPOPEDIA_PATH` (line ~239)

## Resolution Options

### Option 1: Define Constants in oauth-controller.php (Recommended)
Add constant definition at the top of `oauth-controller.php`:

```php
<?php
// Define LUPOPEDIA_PATH if not already defined
if (!defined('LUPOPEDIA_PATH')) {
    define('LUPOPEDIA_PATH', dirname(__FILE__) . '/');
}
?>
```

### Option 2: Modify module-loader.php (Alternative)
Update `module-loader.php` to ensure constants are defined before loading modules:

```php
// Load bootstrap first to ensure constants are available
require_once LUPOPEDIA_ABSPATH . '/bootstrap.php';

// Then load modules
require_once LUPOPEDIA_PATH . '/lupo-includes/modules/module-loader.php';
```

### Option 3: Update File Loading Order in bootstrap.php (Comprehensive)
Ensure `bootstrap.php` loads configuration files before modules:

```php
// Load configuration files first
require_once LUPOPEDIA_ABSPATH . '/lupo-config.php';

// Then load core functions
require_once LUPOPEDIA_ABSPATH . '/functions-core.php';

// Then load auth UI helpers
require_once LUPOPEDIA_ABSPATH . '/functions/auth-ui-helpers.php';

// Then load module system
require_once LUPOPEDIA_ABSPATH . '/modules/module-loader.php';
```

## Recommended Solution: Option 1

**Why Option 1 is Best:**
- **Self-contained**: Each module defines its own required constants
- **No circular dependencies**: Modules don't depend on loading order
- **Clear responsibility**: Easy to see which file defines which constants
- **Minimal changes**: Only affects the problematic file
- **Maintains architecture**: Doesn't change the core loading sequence

**Implementation:**
Add this to the top of `oauth-controller.php`:

```php
<?php
//===========================================================================
//* --                LUPOPEDIA OAuth Controller                -- *
//===========================================================================
//           URL:   https://lupopedia.com/    EMAIL: livehelp@lupopedia.com

// ----------------------------------------------------------------------------

}
```

To prevent similar issues in the future:

1. **Always define required constants** at the top of files that need them
2. **Use dependency injection** - Load dependencies before requiring dependent files
3. **Document constant requirements** in each file's header comments
4. **Test file loading order** - Ensure constants are available when needed

This resolves the immediate PHP fatal error and prevents similar constant definition issues across the module system.
