# Database Function Fix: PDO_DB::fetch() Method Not Found

## Error Analysis

**Fatal Error:**
```
PHP Fatal error:  Uncaught Error: Call to undefined method PDO_DB::fetch() in C:\ServBay\www\servbay\lupopedia\channels\1\index.php:207
```

**Root Cause:**
The `getCurrentActorId()` function in `channels/1/index.php` is calling `$db->fetch()` method, but the database object returned by `DatabaseFactory::getConnection()` is likely a `PDO_DB` wrapper class, not a native PDO object.

## Current Code Analysis

### Problematic Function (channels/1/index.php:207):
```php
function getCurrentActorId($session_id) {
    $db = DatabaseFactory::getConnection();
    $table_prefix = defined('LUPO_TABLE_PREFIX') ? LUPO_TABLE_PREFIX : 'lupo_';
    
    $sql = "SELECT actor_id FROM {$table_prefix}sessions 
              WHERE session_id = :session_id AND is_deleted = 0";
    
    $result = $db->fetch($sql, ['session_id' => $session_id]);  // ← PROBLEM HERE
    return $result ? $result['actor_id'] : 0;
}
```

### Expected Database Class:
Based on the search results, Lupopedia uses a `PDO_DB` wrapper class, not native PDO.

## Solution Options

### Option 1: Use Correct Method Name
**Find the actual method name in PDO_DB class:**
```php
// Check what methods are available in PDO_DB class

```

**Likely method names:**
- `fetchRow()` - For single row results
- `fetchAll()` - For multiple row results
- `fetch()` - May not exist or have different signature

### Option 2: Use DatabaseFactory Helper
**Use the lupo_get_db() helper function:**
```php
function getCurrentActorId($session_id) {
    $db = lupo_get_db(); // Use helper instead

    $sql = "SELECT actor_id FROM {$table_prefix}sessions 
              WHERE session_id = :session_id AND is_deleted = 0";
    
    $result = $db->fetchRow($sql, ['session_id' => $session_id]); // Use fetchRow instead

}
```
