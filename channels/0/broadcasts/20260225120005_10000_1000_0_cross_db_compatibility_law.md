# CROSS-DB COMPATIBILITY LAW

SQL MUST be vendor-neutral to support MySQL 5.7+, MySQL 8.0+, PostgreSQL 12+, and MariaDB 10.2+:

1. **NO UNSIGNED types** - Not supported in PostgreSQL
2. **NO DATETIME/TIMESTAMP** - Use BIGINT with YYYYMMDDHHIISS format
3. **NO Engine hints** - e.g., ENGINE=InnoDB (MySQL-specific)
4. **NO vendor-specific extensions or functions**
5. **NO partial indexes with WHERE clause** - Requires MySQL 8.0.13+ or MariaDB 10.2+ (use regular indexes with all columns)
6. **NO display widths on integer types** - e.g., BIGINT(14) is deprecated (use BIGINT only)
7. **NO AUTO_INCREMENT on non-primary keys** - Not portable across databases
8. **NO database-specific collations** - Use utf8mb4 or utf8mb4_unicode_ci only

**Minimum Supported Versions:**
- MySQL: 5.7+ (target), 8.0+ (preferred)
- MariaDB: 10.2+ (target), 10.5+ (preferred)
- PostgreSQL: 12+ (target), 14+ (preferred)

**Rationale:** Single codebase, multiple engines. Total cross-platform portability. Always test on minimum supported version (MySQL 5.7).

**Recent Violations Fixed (v4.0.46):**
- Partial indexes with WHERE clause (lines 764-767 in install_new_lupopedia.sql)
- Solution: Include filter column in index instead of using WHERE clause
