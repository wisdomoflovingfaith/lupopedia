Fixed the version display issue (second attempt).

**Root Cause:** install.php runs standalone without full bootstrap, so the atom loader in version.php wasn't initialized. The fallback in load_atoms.php was hardcoded to 4.0.27.

**Fixes Applied:**
1. Updated load_atoms.php fallback: 4.0.27 → 4.0.42
2. Added direct YAML parse in install.php to read version from global_atoms.yaml using regex (bypasses atom loader entirely)

install.php now directly parses:
```
GLOBAL_CURRENT_LUPOPEDIA_VERSION: "4.0.42"
```

This works even without bootstrap/atom loader.
