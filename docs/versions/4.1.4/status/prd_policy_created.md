## 2. POLICIES ADDED

### 2.1 Core Constitutional Policies

**Policy 1: No Advertising**
- Absolute prohibition of all advertising systems
- No third-party ads, internal promotions, or affiliate links
- No behavioral targeting or attention manipulation for revenue
- Zero tolerance for any revenue-generating content manipulation

**Policy 2: No Engagement Manipulation**
- Absolute prohibition of engagement optimization
- No dark patterns, addiction loops, or retention mechanics
- No optimization for clicks, time-on-site, or similar metrics
- Truth and clarity must never be compromised for engagement

**Policy 3: Full Transparency**
- All system behavior must be discoverable and documented
- No hidden logic, obfuscation, or concealed systems
- Decisions must be traceable through PRDs, headers, and artifacts
- Users and developers must be able to find any system behavior

**Policy 4: No Hidden Systems**
- No hidden telemetry, tracking, or data collection
- All endpoints and system actions must be visible
- No undisclosed data collection or concealed behavior
- All systems must be explainable and documented

**Policy 5: User Trust Over Growth**
- Clear hierarchy: user trust > growth, truth > engagement, clarity > retention
- User trust always overrides business metrics
- Truth always overrides optimization goals
- Constitutional priority of user trust over system growth

### 2.2 Agent Behavior Rules

**Agent Compliance Requirements**
- Agents must follow these policies above all other goals
- Agents must refuse to generate manipulative UX, ad systems, or hidden behavior
- Agents must not justify violations using "industry standards" or "optimization"
- Zero tolerance for policy violations by any agent

### 2.3 Enforcement Framework

**Violation Classification**
- All violations are system-level failures
- Violations trigger immediate review and correction
- No further development until violations are corrected
- Constitutional enforcement with zero tolerance

### 2.4 Implementation Requirements

**Code-Level Enforcement**
- All code must avoid advertising logic and engagement manipulation
- All code must maintain transparency and document behavior clearly
- Code reviews must check for policy compliance

**System-Level Enforcement**
- All systems must expose behavior through artifacts
- All systems must avoid hidden data collection
- Regular audits required for compliance validation
