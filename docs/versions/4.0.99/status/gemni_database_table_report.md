### 3.3 Analytics Layer (`lupo_paths`, `lupo_referers`)
**Source:** PRD 51 §4.6

- **Current State:** `lupo_paths` and `lupo_referers` exist but seem to be a mix of raw and aggregate data, violating the "Separation of Tiers" doctrine in PRD 51.
