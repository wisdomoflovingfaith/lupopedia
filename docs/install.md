## Upgrade Policy (4.0.x)

**Important:** Lupopedia 4.0.x does **not** support upgrading between versions (e.g., 4.0.1 → 4.0.2, 4.0.76 → 4.0.77). Your options are:

- **Fresh install** of the latest 4.0.x version
- **Upgrade from Crafty Syntax 3.7.5** to the latest 4.0.x

Version-to-version upgrades will be supported starting with **4.1.0**.

See [UPGRADE_POLICY_DOCTRINE.md](doctrine/UPGRADE_POLICY_DOCTRINE.md) for the full policy and implications.
