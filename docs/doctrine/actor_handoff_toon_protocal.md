# ACTOR_HANDOFF_TOON_PROTOCOL

**Captain's Log — 2026-04-18**  
**Doctrine File:** ACTOR_HANDOFF_TOON_PROTOCOL.md  
**Trust Tier:** canonical  
**Scope:** All actors in the Lupopedia Semantic OS (THOTH, MAAT, LILITH, IDE agents, command-line agents, external LLMs, etc.)

### Purpose
This is the official handoff protocol.  
Every actor must write a handoff toon **before** beginning any non-trivial task.  
The handoff toon acts as the actor’s “little notepad” — enabling another actor or the Captain to resume with zero loss of state, context, or doctrine if the current actor dies, crashes, or loses session.

### Mandatory Rule
**Before any non-trivial work begins, the actor MUST create or update its handoff toon.**

**Filename:** `{channel_key}_{actor_id}_handoff.toon`  
**Location:** `memory/handoffs/`

### Required Structure (TOON-M)

Every handoff toon MUST begin with the exact line:

```markdown
# Lupopedia Memory TOON (structured sidecar metadata document — NOT a cartoon)
Minimum JSON structure inside the file:
JSON{
  "type": "handoff",
  "state": "PRE-START",
  "task": "<one-line task description>",
  "timestamp": "<UTC timestamp>",
  "edges": [
    { "type": "disambiguates", "target": "concept:cartoon" },
    { "type": "relates_to", "target": "docs/doctrine/toon_meanings" },
    { "type": "relates_to", "target": "docs/doctrine/ACTOR_HANDOFF_TOON_PROTOCOL" }
  ],
  "notes": []
}

Initial state must be "PRE-START".
As work progresses, update "state" and append to "notes".
The handoff toon is the authoritative recovery document for that actor/task.
