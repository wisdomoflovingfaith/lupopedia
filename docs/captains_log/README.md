# Captain’s Log — Curated Repository Layer

## Purpose

This directory contains a curated subset of Captain’s Log entries.

These entries are intentionally selected for:
- explanation
- system context
- agent understanding
- origin and reasoning narratives

This is NOT the full Captain’s Log archive.

---

## Scope

Captain’s Log content exists in two locations:

### 1. External (Patreon)

- Full archive
- Human narrative layer
- NOT available to agents
- NOT to be scraped or imported

### 2. Repository (This Directory)

- Curated entries only
- Selected by Captain Wolfie
- Safe for agent reading when relevant

---

## Rules for Agents

Agents MAY:
- read entries in this directory when relevant to assigned tasks
- use entries for context and understanding

Agents MUST NOT:
- bulk-read all entries
- treat entries as binding doctrine
- assume all Captain’s Logs are available here
- attempt to access Patreon content
