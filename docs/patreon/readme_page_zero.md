## How the Patreon Is Organized

### The Collection System (00-99 Root Collections + Non-Root Collections)

Lupopedia's Patreon is not a linear feed -- it is a semantic index built from collections. Each numbered root collection maps to a **PRD group number**.

### 1. Collections With Numbers (00-99) = ROOT LEVEL

If a collection's name begins with a number, that number is the PRD group. Examples (not a full list -- see the full map):

- **00** -- Constitutional Root (Forbidden and Why)
- **01** -- Core Identity
- **02** -- Channels
- **05** -- Auth / Actor / Agent Transform
- **07** -- Agents and Faucets
- **15** -- Actors
- **16** -- Headers and Atoms (4.2.0+)
- **25** -- Departments
- **41** -- Captain Wolfie Identity
- **49** -- Questions and Answers (The Crying of Lot 49)
- **50** -- Agent Coordination Protocol
- **51** -- Memory Graph
- **73** -- Collections and Navigation
- **82** -- HERMES Routing and Hawaiian Semantics
- **98** -- Captain Logs / Wolfie Logs / Dual Ops / WHY
- **99** -- Limits for Everything and Why

Vacant numbers (for example 63-69, 81, 90-96) may exist as **HOLD** placeholder collections or may be omitted until needed. Gaps are intentional. Do not renumber.

Root collections are the backbone. They contain constitutional artifacts, PRDs, doctrine, architecture, identity, memory, channels, headers, Q&A, and the log spine.

### 2. Collections Without Numbers = NON-ROOT LEVEL

If a collection does not start with a number -- for example Music Arc, Behind the Scenes, Chaos Notes, Captain's Commentary, Daily Logs, Random Discoveries -- then it is NOT root level.

These collections are supplemental: narrative, commentary, side-stories, experiments, drafts, non-canonical bundles, or special-interest packs. Still important. Not the constitutional backbone.

**Do not** put Captain Logs under `00` or Wolfie Logs under `01`. Those PRD groups are already taken. Logs belong under **98** (with Part 1 / Part 2 / free-vs-paid as tabs or companion non-root titles that still point at 98).

### 3. Every Collection Has a Free Index Page

Every collection -- root or non-root -- has a FREE index page. The index page shows:

- all free entries
- all paid entries
- the recommended reading order
- the collection's purpose
- links to related collections
- the PRD cluster (if applicable)
- the actor identity (if applicable)
- the header version requirement

Index pages are always free because they are part of the navigation system, not the content system.

### 4. Why This Structure Exists

Because Lupopedia is a semantic OS, not a blog. Collections must map to PRD clusters, departments, divisions, actor identities, memory graphs, constitutional fields, narrative arcs, operational logs, doctrine, and system events.

The 00-99 numbering creates a stable, predictable root structure aligned with the repo. Non-numbered collections allow creative freedom without breaking the OS. Free index pages ensure newcomers can always find their way.
