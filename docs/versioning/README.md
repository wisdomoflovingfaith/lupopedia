# Lupopedia Versioning

Lupopedia uses semantic versioning starting at 3.0.0.

Version 3.0.0 is a development-only version used solely by the founder. The first public release will be 4.1.0. There are no patches or minor versions for 3.0.0 because there are no other installations.
