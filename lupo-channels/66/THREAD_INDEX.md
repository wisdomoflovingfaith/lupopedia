# 🧠 Interpretation Model

- **Thread = Question container**  
- **Artifacts = Answers / Attacks / Reviews / Evidence / Closures**  
- Artifacts do **not** need `artifact_kind: question`  
- The **thread defines the question**, not the artifact  

---

# 🔒 Canonical Rules for Channel 66

1. Every thread MUST resolve to a question  
2. The question may be explicit or derived from purpose/task_id  
3. Artifacts may be QA reports, critiques, reconciliations, or closures  
4. THREAD_INDEX.md MUST express the canonical question explicitly  
5. Channel 66 is adversarial: threads are pressure-tests, not summaries  

---

# 🎯 Purpose of This Index

- Make QA work **navigable**  
- Make adversarial reasoning **explicit**  
- Prevent “floating reports” with no question context  
- Anchor every QA artifact to a **question-driven task**  

---

# 🏁 Final Statement

> **Channel 66 is not a collection of reports.  
> It is a structured set of questions being attacked, answered, and resolved.**
