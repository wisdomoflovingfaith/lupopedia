Digit GIFs (digit0.gif … digit9.gif) and blank.gif

The repo ships minimal 1×1 transparent GIFs so URLs resolve. For authentic
legacy tiles matching Crafty Syntax / image.php, copy your handcrafted files
from the old codebase (e.g. craftysyntax images folder) over these files.

Used by:
- channels-api.php format=image (HTTP 302 to /lupo-ui/images/digitN.gif)
- lupo-ui/js/chat-display.js and chat-display-legacy.js (filename detection)
