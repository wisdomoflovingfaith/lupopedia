## 🔗 PROVENANCE EXPANSION (HEADERS 21-30)

### 21. X-Lupo-Provenance-Chain
**Format**: `chain: <actor_id>:<message_id>,<actor_id>:<message_id>,...`
**Purpose**: Identify complete lineage from origin to current message
**Example**: `chain: 420:190,2:191,2038:208`

### 22. X-Lupo-Provenance-Hash
**Format**: `hash: <sha256>`
**Purpose**: SHA-256 hash of message or file content for integrity verification
**Example**: `hash: a1b2c3d4e5f6...`

### 23. X-Lupo-Provenance-Delta
**Format**: `delta: <change_id>:<description>`
**Purpose**: Change identifier from previous artifact state
**Example**: `delta: 001:forwarded_from_420`

### 24. X-Lupo-Provenance-Anchor
**Format**: `anchor: <message_id>`
**Purpose**: Anchor message ID for chain reference and navigation
**Example**: `anchor: 190`

### 25. X-Lupo-Provenance-Mirror
**Format**: `mirror: <archive_type>:<reference_id>`
**Purpose**: Mirror reference to external archive (e.g., 420 file archive)
**Example**: `mirror: file:stoned_420_messages.txt`

### 26. X-Lupo-Provenance-Fork
**Format**: `fork: <fork_id>:<parent_chain>`
**Purpose**: Fork lineage marker for branching narrative paths
**Example**: `fork: 001:420:190,2:191`

### 27. X-Lupo-Provenance-Seal
**Format**: `seal: <timestamp>:<authority_actor_id>`
**Purpose**: Seal status indicating canonical completion of provenance chain
**Example**: `seal: 20260222233800:2038`

### 28. X-Lupo-Provenance-Reconcile
**Format**: `reconcile: <conflict_id>:<resolution>`
**Purpose**: Reconciliation flag for merge conflicts or competing lineages
**Example**: `reconcile: conflict_001:accept_chain_1`

### 29. X-Lupo-Provenance-Ledger
**Format**: `ledger: <ledger_entry_id>`
**Purpose**: Ledger entry ID for audit trail and cross-reference
**Example**: `ledger: LEDGER_001`

### 30. X-Lupo-Provenance-Archive
**Format**: `archive: <storage_type>:<path_or_reference>`
**Purpose**: Archive reference to file path or storage system
**Example**: `archive: file:messages/stoned_420_messages.txt`

## 🜁 CANON/RITUAL (HEADERS 31-36)

### 31. X-Lupo-Canon-Seal
**Format**: `canon_seal: <timestamp>:<seal_type>:<authority>`
**Purpose**: Seal canon event with timestamp and authority validation
**Example**: `canon_seal: 20260222233800:final:2038`

### 32. X-Lupo-Canon-Epilogue
**Format**: `epilogue: <message_id>:<epilogue_type>`
**Purpose**: Epilogue message reference for narrative closure
**Example**: `epilogue: 208:validation_complete`

### 33. X-Lupo-Canon-Freeze
**Format**: `freeze: <target_type>:<target_id>:<reason>`
**Purpose**: Freeze channel or thread state to prevent further modifications
**Example**: `freeze: thread:1:canon_sealed`

### 34. X-Lupo-Canon-Index
**Format**: `canon_index: <index_id>:<volume>:<page>`
**Purpose**: Canon index entry for organized retrieval and reference
**Example**: `canon_index: CI_001:vol1:page42`

### 35. X-Lupo-Canon-Footprint
**Format**: `footprint: <total_count>:<verified_count>`
**Purpose**: Footprint count for tracking and validation
**Example**: `footprint: 13:13`

### 36. X-Lupo-Canon-Witness
**Format**: `witness: <actor_id>:<witness_type>:<timestamp>`
**Purpose**: Witness actor ID for validation and attestation
**Example**: `witness: 2038:validation:20260222233800`
