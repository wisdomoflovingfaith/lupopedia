### Step 2: Remove lupopedia-config.php

Delete the Lupopedia configuration file to ensure a fresh installation.

**Command:**
```bash
# From project root
rm lupopedia-config.php

# Or if it's in parent directory
rm ../lupopedia-config.php
```

**Windows PowerShell:**
```powershell
# From project root
Remove-Item lupopedia-config.php

# Or if it's in parent directory
Remove-Item ..\lupopedia-config.php
```

### Step 3: Load Original Crafty Syntax 3.7.5 Schema

Restore the original Crafty Syntax 3.7.5 database schema (34 legacy tables).

**SQL File:** `database/migrations/old_crafty_syntax_3_7_5_start.sql`

**Command:**
```bash
# MySQL/MariaDB
mysql -u [username] -p [database_name] < database/migrations/old_crafty_syntax_3_7_5_start.sql

# PostgreSQL
psql -U [username] -d [database_name] -f database/migrations/old_crafty_syntax_3_7_5_start.sql
```

**Windows PowerShell (ServBay):**
```powershell
# Adjust paths and credentials as needed
mysql -u root -p lupopedia < database/migrations/old_crafty_syntax_3_7_5_start.sql
```

**Expected Result:**
- 34 `livehelp_*` tables created
- Original Crafty Syntax 3.7.5 schema restored

### Step 4: Restore Original config.php

Copy or restore the original Crafty Syntax 3.7.5 `config.php` file.

**Location:** Project root or parent directory (depending on your setup)

**Note:** This file contains the original Crafty Syntax database credentials and configuration. Ensure it points to the correct database.

### Step 5: Run Lupopedia Installer

Execute the Lupopedia installation wizard to create all Lupopedia tables and perform the upgrade from Crafty Syntax 3.7.5.

**URL:** `http://[your-domain]/[lupopedia-path]/install.php`

**Example:** `http://localhost:8080/lupopedia/install.php`

**Installation Steps:**
1. Open `install.php` in your browser
2. Follow the installation wizard
3. Provide database credentials
4. Select "Upgrade from Crafty Syntax 3.7.5" option
5. Complete the installation process

**Expected Result:**
- All Lupopedia tables created from `database/migrations/install_new_lupopedia.sql`
- Data migrated from Crafty Syntax 3.7.5 tables via `database/migrations/import_from_old_crafty_syntax.sql`
- `lupopedia-config.php` created with new configuration

### Step 6: Import Channels and Artifacts (Optional)

After installation completes, import all Channel 0 broadcasts and artifacts from the filesystem.

**Command:**
```bash
# Run the Python system commands importer
python scripts/import_channels_and_artifacts.py

# Or use the PHP importer if available
php bin/import_system_commands.php
```

**Expected Result:**
- All `.md` files from `channels/` imported to database
- All `.md` files from `artifacts/` imported to database
- Database becomes live reflection of filesystem
