# Progress Summary: Lupopedia 4.0.1 → 4.0.11

Summary of changes from CHANGELOG for versions 4.0.1 through 4.0.11 (Crafty Syntax 3.7.5 → Lupopedia 4.0.x upgrade path only; no Lupopedia→Lupopedia upgrades in this series).

---

## 4.0.1 (2026-02-07)

- **Architecture rebuild:** Structural changes and Crafty Syntax integration preparation. Legacy agent and channel directories removed; new doctrine and TOON files; migration SQLs for actor model and related fixes.
- **Login and session:** New login system (MD5 upgrade path, redirect-back, session upgrade). Collection 0 documentation landing and Q/A module with routing consolidation.
- **Channels and edges:** ChannelsController and EdgesController; routing for channels and edges; placeholder views and 3-panel channel UI skeleton; module-loader and layout updates.
- **Prefix normalization:** Table-prefix normalization completed; dynamic `lupo_` from config; legacy unified tables renamed with `_old` where preserved.
- **Crafty Syntax subsystem:** Operator console under crafty_syntax; operator expertise and AI→human escalation engine; routing, controllers, views for Crafty Syntax module.

---

## 4.0.2 (2026-02-08)

- **Helper refactors:** Domain-by-domain migration of helpers to services/wrappers (Collection Zero, Tabs, Saved Collections, Redirect, Limits, Atoms/Version, Upload). Thin wrappers in `lupo-includes/functions/` call into `app/Services` and `app/Support`.
- **Version doctrine:** Canonical versioning: patch-only 4.0.x; only path Crafty Syntax 3.7.5 → Lupopedia 4.0.x; no Lupopedia→Lupopedia until 4.1.0.
- **Python scripts:** All consolidated under `scripts/`; generators and utilities moved from `database/` and `dialogs/`; doctrine updated.
- **Reserved-word column renames:** One-time migration for MySQL reserved words: `lupo_actor_group_membership.role` → `role_key`, `lupo_artifacts.type` → `entity_type`, `lupo_pack_role_registry.role` → `role_key`. Install schema and API updated.
- **Doctrine and rules:** Mandatory .cursorrules; LUPOPEDIA_DOCTRINE and related docs updated.

---

## 4.0.3 (2026-02-09)

- **PHP 5.3+ compatibility:** Sweep to remove `??` and `[]`; replaced with `isset() ? : ` and `array()`. Session cookie params use 5-argument form (no array form, no samesite). Touched: content-renderer, index, bootstrap, module-loader, topbar, actors-controller, my-profile, admin, layout/view files.
- **Reserved ID doctrine:** `.cursor/rules/reserved-id-doctrine.mdc`. Actors, channels, users: no AUTO_INCREMENT; IDs reserved or explicitly allocated. No `lastInsertId()` for these tables; check existence then UPDATE or INSERT with explicit ID.
- **Schema (install):** Removed AUTO_INCREMENT from `lupo_actors` and `lupo_auth_users` in install SQL.
- **lupo_findpuka():** New helper in reserved-id-helpers.php for next available PK; PDO_DB only. Insert paths (ActorService, LegacyFunctions, run_labs_handshake, channels-controller, AdminUsersHandler, migrate_filesystem_to_db, GroundedAgentModel) updated to use explicit IDs.
- **My Profile save:** Fixed persistence; explicit IDs for actor_properties and uploads.
- **Admin Users (OOP):** Logic moved to `AdminUsersHandler`; admin.php delegates. My Profile UI: timezone dropdown with UTC offsets and labels.
- **Cursor rules:** `.cursor/rules/php-5-3-compatibility.mdc` added.

---

## 4.0.4 (2026-02-10)

- **Identity & actor model:** Unified actor model clarified (humans, system, AI share `actor_id`; relationships use `actor_id` exclusively). README Five Pillars and identity architecture updated.
- **Collection 0:** Seeded correctly; tabs/content/mappings fixed; `debug_collection_zero.php` added; session default `collection_id = 0`; API and JS accept collection 0.
- **Installer & wizard:** Writes `lupopedia-config.php`; renames/removes old Crafty `config.php`; bootstrap prefers lupopedia-config first. BIGINT UTC timestamps in installer/seed.
- **AJAX & UI:** Saved-collections load on page load; default session `collection_id = 0`; loadTabsForCollection on DOM ready; `load_collection_tabs.php` accepts `collection_id = 0`.
- **README & doctrine:** Rewrite: 4.0.x doctrine, unified actor model, Five Pillars, timestamp format, PHP & DB standards, Security Doctrine, Security Audit Doctrine. Quick Start: PHP 5.3–8.3+.
- **Security (LEXA):** Full Security Doctrine and Security Audit Doctrine in README.
- **Seed:** `@now` and BIGINT UTC; idempotent patterns; Collection 0, tabs, contents, mappings seeded.
- **Repository hygiene:** Wolfie Header rules; 156 files touched in stabilization.

## 4.0.5 (2026-02-11)

- **PHP 5.3 (array syntax):** `[]` → `array()` in updated files; rule strengthened; audit report in docs/audits.

All operator terminology/logic removed; livehelp_js, image, install_wizard, channels-controller, AdminUsersHandler, main_layout, README updated.
- **Installer:** Personal channels for Crafty operators (lupo_actor_channel_roles captain); global admin channel 1 (Administration); reserved channels with system actor captain. Wording: "operator channels" → "personal channels and captain roles."
- **Importer:** Confirmed; actor_id = auth_user_id for operators; no lupo_operators; department mapping retained.
- **Permission system:** All checks use `lupo_actor_channel_roles` and `role_key`. channels-controller, AdminUsersHandler, livehelp_js, image updated.
- **Migration:** `migration_operator_to_actor_channel_roles.sql` for existing DBs (channel 1 = Administration; copy lupo_channel_roles → lupo_actor_channel_roles).
- **Docs:** README operator→staff; MIGRATION_DOCTRINE.md and migration-doctrine.mdc; OPERATOR_TO_ROLE_BASED_SWEEP_REPORT, PHP_5_3_ARRAY_SYNTAX_SWEEP_REPORT.

- **Install redirect doctrine:** If lupopedia-config.php does not exist, index.php always redirects to install.php (constitutional).
- **Config after install:** Wizard deletes (not renames) old config.php after writing lupopedia-config.php; safety checks.
- **lupo_channel_roles removal:** Table removed from install; dual-write removed; AuthRoleResolver, AuthManager, livehelp-js, visitor-image, choosedepartment, operator-accept-visitor-api use lupo_actor_channel_roles. migration_drop_lupo_channel_roles.sql added.
- **System department (department_id = 0):** Department 0 = System, department 1 = General; seeded in seed and import. ensureSystemDepartment / ensureDefaultDepartment; department 0 protected (not editable/deletable, hidden in UI). LUPO_SYSTEM_DEPARTMENT_ID = 0.
- **3-layer permission model:** Channel roles (lupo_actor_channel_roles) → department roles (lupo_department_roles) → system (department 0). AuthRoleResolver, AuthService, auth-helpers; hasAdminForChannel, getDepartmentIdForChannel.
- **Channel → department link:** All channels have department_id; permission checks use it for layer 2.
- **Installer/importer/wizard:** ensureSystemDepartment, ensureDefaultDepartment; import ensures departments 0 and 1; Crafty admins to department 0; department 0 hidden in UI.
- **PHP 5.3 sweep (continued):** array() only; operator-accept-visitor-api fixes (??, [], Throwable, gmdate).
- **Migrations:** migration_drop_lupo_channel_roles.sql; migration_system_department_and_admin_roles.sql (department_roles, department 0/1, assign admins to department 0).
- **Versioning & docs:** VERSIONING_DOCTRINE 4.0.6; REQUIRED_TABLES_4.0.6.md; TOONs regenerated.
