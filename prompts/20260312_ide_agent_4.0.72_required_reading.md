## 8. Rules and constraints (reference when editing)

Doctrine enforced in `.cursor/rules/` and `lupo-rules/root/`. Key rules:

- **.cursor/rules/toon-source-of-truth.mdc** — TOONs from install SQL; no code that assumes tables/columns not in TOONs.
- **.cursor/rules/flip-doctrine.mdc** — LUPOPEDIA HEADERS (FLARE/FLIP deprecated); link to header format.
- **.cursor/rules/lupopedia-headers-file-order.mdc** — First line `---`; identity line after closing `---`; no duplicate header blocks.
- **.cursor/rules/php-5-6-compatibility.mdc** — PHP 5.6+; no `??`, no `[]` arrays, no Composer/outside frameworks not in lupo-includes.
- **.cursor/rules/pdo-db-database-access-doctrine.mdc** — All DB via PDO_DB; prepared statements; table prefix.
- **.cursor/rules/database-logic-prohibition-doctrine.mdc** — No FKs, triggers, procedures, UNSIGNED, TIMESTAMP/DATETIME; BIGINT YYYYMMDDHHIISS UTC.
- **.cursor/rules/reserved-id-doctrine.mdc** — Registry-backed tables: explicit ID; no AUTO_INCREMENT for actor/channel/user IDs; SELECT then UPDATE or INSERT.
- **.cursor/rules/single-install-no-4.0-upgrade-doctrine.mdc** — No Lupopedia→Lupopedia upgrade until 4.1.0; Crafty 3.7.5 → 4.0.x only.
