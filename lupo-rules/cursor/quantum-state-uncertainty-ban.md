# Quantum State & Uncertainty-Metadata Ban (PERMANENT)

Cursor MUST NOT reintroduce or reference quantum-state, uncertainty-metadata, or Schrödinger-style metaphors. These concepts are not part of Lupopedia's doctrine or semantic OS. This rule complements stoned-wolfie-schrodinger-ban.

## Forbidden concepts

- **Quantum state / quantum_state / quantum-state / quantumState** — Do not add as doctrine, metadata, workflow, or code. No "quantum metadata," "quantum header," "quantum doctrine."
- **Uncertainty metadata / uncertainty_state / uncertainty_metadata / uncertainty-model / uncertainty vector / uncertainty atom** — Do not add as first-class metadata or doctrine.
- **Superposition / collapse_state / wavefunction / probability cloud** — Do not use as doctrine or workflow concepts.
- **schrodingers_state** and variants — Forbidden (see stoned-wolfie-schrodinger-ban).
- **QuantumStateManager / QuantumStateSnapshot** — Removed; do not recreate or reference.
- **Conceptual metaphors:** "uncertainty-based workflow," "quantum-inspired decision model," "state collapse," "observer-dependent state," "probabilistic metadata," "indeterminate state," "dual-state metadata" — Do not add as doctrine or documentation.

## Rules

- Never add a file, section, or metadata field that prescribes quantum-state or uncertainty-metadata doctrine.
- Never add YAML/JSON/frontmatter blocks or TOON fields for quantum_state, uncertainty_metadata, superposition, or observer-collapse.
- Never create or reference QUANTUM_STATE_DOCTRINE, SCHRODINGERS_STATE_BLOCK, or quantum-state PHP/doctrine files.
- If you find remaining references in historical docs (e.g. CHANGELOG, dialogs), treat them as historical only; do not propagate into new content.

Optional discovery-context or version-alignment metadata is allowed only when it does not use "quantum," "superposition," "uncertainty" (as a metadata type), or "Schrödinger" (see stoned-wolfie-schrodinger-ban and wheeler-reverse20-ban).

This rule is permanent. These concepts are invalid and non-existent for new work.
