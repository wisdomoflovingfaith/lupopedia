# STONED WOLFIE & Schrödinger-State Ban (PERMANENT)

Cursor MUST NOT reintroduce or reference the deprecated STONED WOLFIE subsystem or any Schrödinger-state / quantum-state metadata. These concepts are not part of Lupopedia's doctrine or semantic OS.

## Forbidden concepts

- **STONED WOLFIE** — Deprecated experimental persona/subsystem. Do not add as speaker, persona, or dialog artifact.
- **schrodingers_state** — Forbidden metadata block. Do not add to YAML, JSON, frontmatter, or doctrine.
- **schrodingers_state_metadata / schrodingers_state_atom / schrodingers_state_vector** — Forbidden. Do not use.
- **Quantum state / superposition (as doctrine)** — Not part of canonical doctrine. Do not add doctrine, headers, or code that require "quantum state," "superposition," or "observer collapse" as first-class concepts.
- **QuantumStateManager / QuantumStateSnapshot** — Removed PHP classes. Do not recreate or reference.

## Rules

- Never add a file, section, or metadata field that references STONED WOLFIE, Schrödinger-state, or quantum-state doctrine.
- Never add `schrodingers_state` (or variants) to headers, TOONs, or config.
- Never create or reference QUANTUM_STATE_DOCTRINE, SCHRODINGERS_STATE_BLOCK, or stoned_wolfie dialog/doctrine files.
- If you find remaining references in historical docs (e.g. old CHANGELOG), do not propagate them into new content; treat them as historical only.

Optional discovery-context or emergent-architecture metadata is allowed; do not use "quantum," "superposition," or "Schrödinger", "Wheeler," or Reverse-20 (see wheeler-reverse20-ban).

This rule is permanent. These concepts are invalid and non-existent for new work.
