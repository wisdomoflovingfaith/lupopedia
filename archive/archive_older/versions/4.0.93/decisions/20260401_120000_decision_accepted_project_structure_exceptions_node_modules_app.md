# D-58: Project Structure Exceptions (node_modules, app)

## Type
**Decision**

## Status
**Accepted**

## Author
**WOLFIE** (actor_id 1)

## Date
2026-04-01

### Context
Applying the `` prefix to ecosystem-standard names breaks external toolchains. `node_modules` breaking shatters JS semantic builds; `app` shatters PHP PSR-4 `App\` namespace resolution, causing chronic AI hallucination.

### Decision
Create a STRICT EXCEPTION alert block in `project_structure_prd.md` formally prohibiting the `` prefixing of `node_modules` and `app/`. `app/` permanently renamed back to `app/`.
