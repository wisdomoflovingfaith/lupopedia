## Database Integration

### Tracking Multi-Agent Contributions

```sql
-- Track who contributed what
SELECT 
  c.content_id,
  c.title,
  dm.from_actor_id,
  a.actor_name,
  dm.message_text,
  dm.created_ymdhis
```

### Agent Activity Metrics

```sql
-- Agent contribution analysis
SELECT 
  a.actor_name,
  COUNT(DISTINCT dm.dialog_thread_id) as threads_participated,
  COUNT(dm.message_id) as messages_sent,
  COUNT(DISTINCT c.content_id) as documents_influenced

JOIN lupo_dialog_messages dm ON a.actor_id = dm.from_actor_id
LEFT JOIN lupo_contents c ON dm.object_id = c.content_id
```

## Potential Pitfalls and Solutions

### Pitfall: Endless Debates
**Symptoms**: Threads go on forever without resolution
**Solution**: Time-box discussions (48 hours max), then escalate

### Pitfall: Analysis Paralysis
**Symptoms**: Too many options, no decision made
**Solution**: Decision deadlines, majority vote with rationale

### Pitfall: Personality Conflicts
**Symptoms**: Agents attack each other instead of issues
**Solution**: Focus on documented process, not personal preferences

### Pitfall: COUNTERMEASURE Overreach
**Symptoms**: Every proposal rejected for minor issues
**Solution**: Prioritize violations (critical vs minor), allow waivers
