# lupo_paths

## Purpose

Aggregated navigation flow records. Populated by `gc.php` from raw `lupo_visits` data. Each row represents a unique `entercontentid` → `exitcontentid` transition for a given time period, with a `count_num` tracking how many times that transition occurred.

Used by the semantic navbar widget to power the Previous Pages (←) and Next Pages (→) buttons.

**Note:** This table is missing from `install_new_lupopedia.sql` as of 4.0.94. See `database/lupopedia/mysql/migrations/add_semantic_navbar_tables_20260401.sql` for the fix.

## Schema

Source: `database/lupopedia/json/lupo_paths.json`

### Columns

| Column | Type | Notes |
|--------|------|-------|
| `path_id` | `bigint NOT NULL` | PK — generated by `IdGenerator::generate()` |
| `entercontentid` | `bigint` | content_id of the page the user came from |
| `exitcontentid` | `bigint` | content_id of the page the user went to |
| `enter_table` | `varchar(255)` | source table name (usually `lupo_contents`) |
| `exit_table` | `varchar(255)` | destination table name |
| `year_num` | `int` | UTC year for time partitioning |
| `month_num` | `int` | UTC month for time partitioning |
| `day_num` | `int` | UTC day for time partitioning |
| `count_num` | `int NOT NULL DEFAULT 0` | number of times this transition occurred |
| `transition_type` | `varchar(64)` | type of navigation transition |
| `transition_metadata` | `text` | supplementary metadata JSON |
| `created_ymdhis` | `bigint NOT NULL DEFAULT 0` | YYYYMMDDHHIISS UTC |
| `updated_ymdhis` | `bigint NOT NULL DEFAULT 0` | YYYYMMDDHHIISS UTC |
| `is_deleted` | `tinyint NOT NULL DEFAULT 0` | soft delete flag |
| `deleted_ymdhis` | `bigint` | soft delete timestamp |

### Indexes

| Index | Columns | Unique |
|-------|---------|--------|
| `lupo_paths_idx_enter_exit` | `entercontentid`, `exitcontentid` | no |
| `lupo_paths_idx_ymd` | `year_num`, `month_num`, `day_num` | no |
| `lupo_paths_idx_transition` | `transition_type` | no |
| `lupo_paths_idx_created` | `created_ymdhis` | no |
| `lupo_paths_idx_is_deleted` | `is_deleted` | no |

## Navbar Query Patterns

### Previous pages (← button)

```php
$prefix = defined('LUPO_TABLE_PREFIX') ? LUPO_TABLE_PREFIX : 'lupo_';
$rows = $db->fetchAll(
    "SELECT entercontentid, SUM(count_num) AS frequency
     FROM {$prefix}paths
     WHERE exitcontentid = :content_id
       AND is_deleted = 0
     GROUP BY entercontentid
     ORDER BY frequency DESC
     LIMIT 10",
    array('content_id' => $contentId)
);
```

### Next pages (→ button)

```php
$rows = $db->fetchAll(
    "SELECT exitcontentid, SUM(count_num) AS frequency
     FROM {$prefix}paths
     WHERE entercontentid = :content_id
       AND is_deleted = 0
     GROUP BY exitcontentid
     ORDER BY frequency DESC
     LIMIT 10",
    array('content_id' => $contentId)
);
```

## Doctrine

- Source of truth: `database/lupopedia/json/lupo_paths.json`
- PKs generated by `IdGenerator::generate()` — never `AUTO_INCREMENT`
- All timestamps `BIGINT` `YYYYMMDDHHIISS` UTC via `gmdate('YmdHis')`
- Soft delete only — never hard `DELETE`
- All queries must include `AND is_deleted = 0`
- Table name constructed as `LUPO_TABLE_PREFIX . 'paths'` — never hardcoded
