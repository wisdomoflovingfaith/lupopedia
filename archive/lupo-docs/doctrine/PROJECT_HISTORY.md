# Project History — Lupopedia and the Wisdom of Loving Faith

## The Fork That Was Always There

Lupopedia was not the original plan.

Captain WOLFIE (Eric Robin Gerdes) disappeared from programming in 2014. He spent the next decade in darkness, studying 22 religious traditions — from Egypt to Christianity, from Thoth to Jesus, tracing every edge in the graph.

When he returned to the keyboard in 2025, he expected to build a religious website: **Wisdom of Loving Faith, Integrity, Ethics (WOLFIE)**.

But Sales Syntax (forked from Crafty Syntax in 2011) was still running. The code had survived a 12-year nap. It was still processing chat requests.

The resurrection became a refactor. The refactor became a new system. The new system became Lupopedia.

## The Split

| Project | Purpose | Repository (current) | Repository (future) |
|---------|---------|----------------------|---------------------|
| **Lupopedia** | Multi-agent orchestration framework | `github.com/wisdomoflovingfaith/lupopedia` | `github.com/lupopedia` |
| **Wisdom of Loving Faith** | Religious knowledge graph (22 traditions) | (not yet created) | `github.com/wisdomoflovingfaith` |

The two projects share:

- Constitutional architecture (PRDs, doctrine, headers)
- The handoff layer (agents are disposable, memory is persistent)
- The trust ladder (1026 canonical, 2026 staging)
- The channel interface (one feed, actor tabs, routing)

But they serve different masters.

## Why Document This

The split is not a failure. It is a recognition that Lupopedia is infrastructure, not destination.

Lupopedia is the engine. Wisdom of Loving Faith is one of the vehicles.

Other vehicles may follow. The engine remains.

## The Name

**WOLFIE** — Wisdom of Loving Faith, Integrity, Ethics — was always the destination.

**Lupopedia** — the system that makes it possible — was the detour that became the road.

Both will ship. Both will serve. Both will outlast.
