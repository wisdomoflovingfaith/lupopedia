# Concept: Lupopedia as Human + AI Shared Workspace

## Internal Technical Wording (Layer 3)
Lupopedia is natively a hybrid orchestration environment. Humans and designated AI actors route data, process tasks, and modify filesystem schemas across identical channel interfaces. Roles are partitioned structurally, but the runtime does not privilege human DOM generation over autonomous semantic manipulation; the repo is the shared execution state.

## Conceptual Model (Layer 2)
Imagine an office where the human and the AI sit side-by-side at the same desk, looking at the same paperwork, and talking in the same team chat. Neither has a secret hidden dashboard. They collaborate transparently on equal footing using the exact same files and systems.

## External Short Wording (Layer 1)
Humans and AI systems work together in Lupopedia using the exact same tools and the exact same interface, ensuring total transparency.

## Business Wording
Lupopedia operates as a unified hybrid workspace, aligning human contributors and AI worker agents within a single operational context. This unification reduces procedural friction, enforces identical compliance auditing for all changes, and ensures absolute visibility across both human and automated operations.

## User-Guide Wording
You and the AI team members will be using the same tools and sharing the same workspace. You can assign tasks to them just like a human coworker, and they will work on the same shared screens you see.

## Developer Wording
Do not build "AI-only" backdoors or hidden configuration tiers. If an agent executes an action, it must be logged and routed exactly like a human user's action through the `channels/index.php` interfaces. The architecture is symmetrically hybrid.

## Example Analogy
It's a surgical operating room. The human surgeon and the robotic assistant both stand over the same patient, use same instruments, and talk to the same nurses. 

## Common Misunderstanding
"The AI lives in a hidden server running background cron jobs."
*Correction*: The AI operates visibly in the same active channels as the humans and its work is reviewed via standard PRDs.

## Wording to Avoid
* "Chatbot window"
* "AI Plugin"
* "Black box algorithm"
