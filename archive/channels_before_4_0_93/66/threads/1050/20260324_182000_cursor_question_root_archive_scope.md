# Question: Root Archive Scope

What exact root-file classes should always be archived by default in production hygiene passes?

## Proposed defaults
- temporary debug files (`tmp_*`, `_tmp_*`, `_iter*`)
- empty run outputs (`*.txt` generated by one-off diagnostics)
- per-agent root variants once canonical consolidated artifacts exist

## Needed answers
1. Should per-agent changelog/plan/report variants remain discoverable at root or only under `docs/archived/`?
2. What retention SLA applies for temporary debug scripts moved to archive?
3. Should a protected allowlist be enforced for root files that cannot be moved automatically?
