# Thread 1047: Multi-Channel Metadata Ownership & Headers (Consultation Questions)

## Status

⏳ **AWAITING EXTERNAL CONSULTATION** — Non-blocking for 4.0.87  
**Routing**: ROSE (external consultation facilitator)  
**Esperado Response**: DeepSeek or equivalent external AI system  
**Impact**: Future releases (4.0.88+); informs header ownership architecture

## Overview

Three critical architectural questions about how Lupopedia handles metadata (especially LUPOPEDIA HEADERS) when the same file appears in multiple channels:

1. **Header Reimport Safety & Determinism** — Can we safely re-import headers without data corruption?
2. **Multi-Channel Ownership Model** — How do we handle authoritative versions when same file in multiple channels?
3. **Header Immutability vs. Editability** — Should headers be generated-only or mutable with versioning?

These questions don't block 4.0.87 release but are critical for long-term system design.

## Context

- **Prior Work**: Phase 2 edge graph implementation (threads 1050-1053) resolved immediate architecture questions
- **New Challenge**: With Channel 66 multi-actor usage, files are now appearing in multiple channels. Which channel's metadata is "correct"?
- **External Perspective Needed**: These are design pattern questions that benefit from seeing how other systems solve similar problems

## The Three Questions

### Question 1: Header Reimport Safety & Determinism
**Doc**: [20260324_195300_q1_header_reimport_safety.md](20260324_195300_q1_header_reimport_safety.md)  
**Key Issue**: If we regenerate headers from database, can we guarantee identical output?  
**Why It Matters**: Determinism = developers can trust auto-generation; non-determinism = must manually verify  

### Question 2: Multi-Channel Header Ownership  
**Doc**: [20260324_195300_q2_multichannel_ownership.md](20260324_195300_q2_multichannel_ownership.md)  
**Key Issue**: When same file lives in 2+ channels, whose metadata is authoritative?  
**Why It Matters**: Prevents conflicts, ensure consistency, defines what "sync" means  

### Question 3: Header Immutability vs. Editability
**Doc**: [20260324_195300_q3_immutability_tradeoff.md](20260324_195300_q3_immutability_tradeoff.md)  
**Key Issue**: Can developers edit headers manually, or are they generated-only?  
**Why It Matters**: Affects developer experience (control vs. automation)
