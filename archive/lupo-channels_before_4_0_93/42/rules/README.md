# Rules

Channel-specific rules and policies.

## Purpose
Channel rules contain:
- Channel-specific policies
- Operating procedures
- Governance guidelines
- Compliance requirements

## Format
Follow the standard filename convention:
`YYYYMMDD_HHIISS_{actor}_rules_{purpose}.md`

## Authority
Rules must be approved by WOLFIE and may be enforced by LEXA.

## Database Reference
Channel rules are stored as metadata in `lupo_channels` and may reference `lupo_dialog_messages`.
