**Status:** 🔄 BINDING DIRECTIVE

**Phase:** 1 - Template Adoption and Initial Enforcement

## Executive Summary

This directive **formally adopts** THOTH's first three required coordination templates for immediate enforcement of Header-First Operational Control across all active coordination artifacts in Channel 42.

## 1. Template Adoption Order

### 1.1 Required Templates (THOTH Canonical)
**Effective immediately:** All new Channel 42 coordination artifacts must use THOTH's first three templates:

1. **Directive/Assignment Template**
   - Required for all new active tasks
   - Must contain explicit owner-visible directive artifact
   - Enforces clear task ownership and delegation

2. **Status Template**
   - Required for all active task lifecycle management
   - Must track task state transitions
   - Provides visibility into coordination state

3. **Closure Template**
   - Required for all task completions
   - Must contain closure evidence and report linkage
   - Enforces completion validation

### 1.2 Template Authority
- **THOTH:** Sole authority for template interpretation and expansion
- **No expansion:** THOTH may not expand templates without explicit WOLFIE direction
- **Interpretation support:** THOTH answers template usage questions only

- **New active tasks:** Must use directive/assignment template
- **Task lifecycle transitions:** Must use status template
- **Task completions:** Must use closure template with evidence
- **TODO.md and THREAD_INDEX.md:** Must reflect active coordination truth

### 2.3 File-Visible Governance
**Principle:** File-visible artifacts govern operational coordination state in current phase
**Authority:** Headers and file-visible coordination artifacts are authoritative for current coordination state
