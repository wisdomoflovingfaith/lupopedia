## What Lupopedia Is (Technical Truth)

Lupopedia is the continuation of **Crafty Syntax Live Help 3.7.5** — the almost 30‑year‑old PHP live‑chat program Captain Wolfie began programming last century in 1999 and first released in February 2002 — now rebuilt into a **doctrine‑driven semantic OS**. Estimated release of the first stable Lupopedia version **4.2.0** is expected sometime in June 2026.

It preserves the lineage while transforming the architecture:

- actors, channels, sessions, and explicit rules instead of framework magic
- a single supported data path from Crafty Syntax 3.7.5 → Lupopedia 4.1.x / 4.2.x
- PDO‑only database access
- BIGINT UTC timestamps
- no Laravel‑style middleware
- shared‑hosting friendly (cPanel, Installatron, Softaculous)
- plain PHP with hand‑authored UI where doctrine requires it
- heavy use of **LUPOPEDIA HEADERS** and **PRDs** so humans and agents operate from the same written contract

In short: It’s a live‑help lineage product fused with orchestration, identity, and documentation machinery for multi‑agent work on one codebase.
