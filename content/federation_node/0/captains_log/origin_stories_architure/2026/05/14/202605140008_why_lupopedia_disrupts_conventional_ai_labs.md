## Lineage & Architecture

It is the continuation of **Crafty Syntax Live Help 3.7.5**: a PHP live-chat and site stack rebuilt as a doctrine-driven semantic OS with actors, channels, sessions, and explicit rules instead of framework magic.

It preserves a single supported data path from Crafty Syntax 3.7.5 into Lupopedia 4.0.x / 4.1.x (fresh install from canonical SQL + seed), using:

- PDO-only database access
- BIGINT UTC timestamps
- No Laravel-style middleware

The project targets shared hosting and packaged installs (cPanel-style flows), with plain PHP, hand-authored UI where doctrine requires it, and heavy use of **LUPOPEDIA HEADERS** and **PRDs** so agents and humans operate from the same written contract.

In short: it is a live-help lineage product fused with orchestration, identity, and documentation machinery for multi-agent work on one codebase.
