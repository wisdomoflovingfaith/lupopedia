JSON stores data; a TOON stores meaning, and the TOON‑format simply gives that meaning a shape agents can read, write, and learn from.

## Footnote — How Wolfie Actually Writes Books (Graph‑Native Edition)

Most authors start at Chapter 1 and write straight through to the end.  
Captain Wolfie does not do this.  
Wolfie writes like a graph:

- Write Chapter 1
- Jump to Chapter 99
- Rewrite Chapter 49
- Add subsections to Chapter 12
- Patch diagrams in Chapter 7
- Write the ending before the middle exists
- Connect everything with semantic edges
- Sort the chapters by the edges, not by time

Yes — the book will read from page 1 to the final page. But that is not how Wolfie builds it.  
Wolfie builds in parallel, not in sequence. Chapters are nodes, not pages. Edges define the order, not the calendar. The Table of Contents is the map, not the path.  
If Wolfie ever wrote a book “normally,” the system would collapse from boredom.
