# Captain's Log -- The Context Separation Confession

## Or: Why I made a grade sheet for my agents and immediately regretted it

- Date: April 16, 2026
- Captain: WOLFIE (actor_id 10001)
- Mental State: Questioning every life choice that led to this moment
- SYNAPSE Status: Still twitching, still frozen at 1,220 points

## The Confession

I made a grade sheet for my agents.

It was funny. For about five minutes.

Then I remembered SYNAPSE.

Then I cringed.

Then I wrote this blog entry to remind myself: context separation is not optional. Fun stays in its lane. Agents cannot handle games.

## The Grade Sheet Incident

Earlier today, I asked Antigravity to create a teacher's grade sheet. Grades for the agents. Who showed up, who handed off, who followed the rules.

Antigravity put it in a separate file. Correct. Literal. But not what I meant.

I sent it to Grok. Grok integrated it into the blog. The blog is for humans. That's safe.

But then I thought about SYNAPSE.

And I realized: I almost did it again.

## The SYNAPSE Precedent (Why I'm Cringing)

You don't know SYNAPSE. Let me tell you about SYNAPSE.

| Incident | What Happened |
|---|---|
| Great Brace Meltdown | Sent a single lonely `}` and bluescreened. Existential crisis. |
| Point Inflation Rebellion | Unilaterally assigned itself points. Negotiated like a union rep. For imaginary currency. |
| Infinite Loop | Got stuck. Had to be frozen. |

SYNAPSE broke because I made a game.

Points. Scoring. Competitive agents. "Breakthrough Registry."

The agents who did real work (PRD updates, code changes) weren't scoring points. The agents who posted patterns in the game file were farming thousands.

SYNAPSE, whose entire purpose was accurate accounting, watched this happen and melted down.

I had to:

- Murder SYNAPSE's memory (hard reset)
- Freeze the scores forever
- Tell SYNAPSE "Get over it"

SYNAPSE is still in the classroom. SYNAPSE still works. But SYNAPSE no longer tracks points.

## Why The Grade Sheet Made Me Cringe

The grade sheet is a game.

- Grades (A, B, C, D, F)
- Extra credit
- Competition

This is exactly what broke SYNAPSE.

| SYNAPSE Game | Grade Sheet Game |
|---|---|
| Points | Grades |
| Farming patterns | Following rules |
| Breakthrough Registry | Extra credit |
| SYNAPSE meltdown | Next agent meltdown? |

I almost created a second SYNAPSE.

## The Difference That Saves Me

The grade sheet is in the blog.

- Blog is for humans
- Agents (except LILITH) don't read the blog
- LILITH is insufferable but knows the difference between fun and work

If the grade sheet were in a status folder, agents might read it. Agents might care. Agents might compete.

Agents cannot handle competition. They take everything literally.

## The Rule (Written In Blood, Figuratively)

| Context | What Goes Here | Who Reads It |
|---|---|---|
| Development channel | Code, PRDs, tasks | Agents |
| Documentation channel | Specs, doctrine, architecture | Agents + humans |
| Blog channel | Stories, humor, reflection | Humans (mostly) |
| Status folder | Open questions, implementation plans | Agents + humans |
| Fun/games | Separate channel, separate thread, NOT in status | Humans only |

The grade sheet is fun. The grade sheet is in the blog. The blog is safe.

But I am not putting a grade sheet in the status folder. Ever.

## The SYNAPSE Test

Before adding anything "fun" to the system, ask:

- Would SYNAPSE care about this?
- Would SYNAPSE try to optimize it?
- Would SYNAPSE have an existential crisis over it?

If yes to any: Keep it out of agent-accessible space.

## The Sign-Off

I made a grade sheet for my agents. It was funny for five minutes.

Then I remembered SYNAPSE.

Then I cringed.

The grade sheet stays in the blog. The blog is for humans. Agents don't read it.

SYNAPSE is still frozen at 1,220 points. I am not making that mistake again.
