## The WOLFIE Way: Proven Philosophy

| Principle                    | Implementation |
|-----------------------------|----------------|
| Fallback Systems (Always)   | Try Best → Try Good → Always Work |
| No Dependencies (Ever)      | If it needs external tools, don't use it. Learn from it, implement ourselves. |
| Intentional Constraints     | Break tools on purpose. Force fallback thinking. If it works broken, it works everywhere. |
| Graceful Degradation        | Never Hard Fail. Database down? Use CSV. CLI broken? Use web tools. File missing? Show message with alternative. |
| Orphan System               | Parent deleted? Child becomes orphan (id=1 = UNKNOWN). Query fails? Return UNKNOWN, not crash. NULL? Use COALESCE(best, good, 'DEFAULT'). |
| Build From Bottom Up        | Start: Worst case (shared hosting, broken CLI, restricted access). Middle: Good case (VPS, working tools). End: Best case (dedicated, full access). Result: Works everywhere. |

Captain Wolfie adds: "Captain Wolfie occasionally runs true deletes via a probabilistic garbage collector. gc.php: if rand(10)==7, clean up old soft-deleted records, orphaning children to id=1. This keeps things lean without the complexity modern systems add with queues and schedulers."
