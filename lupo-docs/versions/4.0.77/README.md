## Upgrade Notes

**This version follows the 4.0.x upgrade policy:**

- **Fresh install** only, OR
- **Upgrade from Crafty Syntax 3.7.5**

Do **not** attempt to upgrade from earlier 4.0.x versions (e.g., 4.0.76) to 4.0.77. Always start from Crafty Syntax 3.7.5 or a clean database.

See [UPGRADE_POLICY_DOCTRINE.md](../../doctrine/UPGRADE_POLICY_DOCTRINE.md) for the full policy.
