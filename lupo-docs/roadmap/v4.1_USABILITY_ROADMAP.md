# 🚀 V4.1 USABILITY ROADMAP: FROM DOCTRINE TO AUTOMATION

Following LILITH's critical review (20260224), this roadmap outlines the transition from purely manual doctrine enforcement to automated, high-speed multi-agent orchestration.

## 🎯 OBJECTIVE
Reduce semantic friction by 70% and enable sub-second multi-agent delegation verification.

---

## 🏗️ PHASE 1: SEMANTIC FOUNDATIONS (Current Cycle)

### 1.1 Delegation Chain Rename
- **Task**: Fully migrate from `x_lupo_forwarded` to `delegation_chain`.
- **Status**: ✅ Types updated, ✅ Doctrine updated, 🔄 Parser migration in progress.
- **Audit Rule**: Every operational artifact MUST have a `delegation_chain` ending in a human ID (>= 10000).

### 1.2 JSON5 Migration
- **Task**: Update `YamlExtractor.ts` to fully support JSON5 (comments, trailing commas).
- **Benefit**: Human-readable metadata documentation inline with code.
- **Target**: All new 4.0.37+ artifacts should prefer JSON blocks over YAML for metadata.

---

## 📡 PHASE 2: VSX USABILITY OVERHAUL (Next Cycle)

### 2.1 One-Command Validation
- **Command**: `Lupopedia: Validate delegation_chain`
- **Logic**: 
    1. Parse chain elements.
    2. Verify ID ranges.
    3. Cross-reference with `ArtifactIndex` or Database.
    4. Provide actionable remediation UI.

### 2.2 Semantic Query Commands
- **Command**: `Lupopedia: Query Artifacts`
- **Presets**:
    - `by_human: [ID]`
    - `by_agent: [ID]`
    - `active_delegation_paths`
    - `orphan_artifacts` (no valid chain)

### 2.3 Visual Delegation Explorer
- **Feature**: A webview rendering a Mermaid/D3 graph of the current delegation tree.
- **Visualization**: Show how the Captain's intent trickles down through KIRO, Antigravity, and other agents.

---

## 🐝 PHASE 3: SWARM ORCHESTRATION (v4.1 Target)

### 3.1 Parallel Delegation Pools
- **Concept**: Delegate a task to a `delegation_pool` rather than a single agent.
- **Strategy**: Support `parallel`, `round_robin`, and `fastest_first` execution modes.

### 3.2 Automated Remediation
- **Feature**: The extension automatically fixes common header errors (e.g., outdated actor IDs, missing human principal).

### 3.3 Performance Metrics Dashboard
- **Feature**: Track agent "Success Rate" and "Semantic Latency" directly in the LUPO UI.
