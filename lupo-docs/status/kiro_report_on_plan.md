## 8. New Table Proposal: `lupo_projects`

### 8.1 Rationale

Lupopedia currently has no first-class concept of a **project** — a named unit of work scoped to a specific channel, orchestrator, and federation node. Projects are needed to:

- Group work (tasks, actors, artifacts) under a named initiative
- Scope a project to exactly one channel (where its activity lives)
- Assign exactly one orchestrator actor (the responsible agent/human)
- Bind a project to exactly one federation node (the domain it belongs to)
- Support federated multi-domain collaboration (e.g. a project on `collaborativepages.com` vs local node)

### 8.2 Proposed DDL

```sql
-- lupo_projects: project registry scoped to channel, orchestrator, and federation node
-- DOCTRINE: one channel per project, one orchestrator per project, one node per project
CREATE TABLE lupo_projects (
  project_id        bigint NOT NULL,
  project_key       varchar(64) NOT NULL,
  project_name      varchar(255) NOT NULL,
  project_slug      varchar(255) NOT NULL,
  description       text,
  channel_id        bigint NOT NULL,
  orchestrator_id   bigint NOT NULL,
  federation_node_id bigint NOT NULL,
  status            varchar(32) NOT NULL DEFAULT 'active',
  project_type      varchar(64) NOT NULL DEFAULT 'general',
  metadata_json     json DEFAULT NULL,
  created_ymdhis    bigint NOT NULL DEFAULT 0,
  updated_ymdhis    bigint NOT NULL DEFAULT 0,
  is_deleted        tinyint NOT NULL DEFAULT 0,
  deleted_ymdhis    bigint NOT NULL DEFAULT 0,
  PRIMARY KEY (project_id),
  UNIQUE KEY lupo_projects_unq_key_per_node (project_key, federation_node_id)
);
CREATE INDEX lupo_projects_idx_channel      ON lupo_projects (channel_id);
CREATE INDEX lupo_projects_idx_orchestrator ON lupo_projects (orchestrator_id);
CREATE INDEX lupo_projects_idx_node         ON lupo_projects (federation_node_id);
CREATE INDEX lupo_projects_idx_status       ON lupo_projects (status);
CREATE INDEX lupo_projects_idx_is_deleted   ON lupo_projects (is_deleted);
```

### 8.3 Column Notes

| Column | Type | Notes |
|--------|------|-------|
| `project_id` | bigint | Not AUTO_INCREMENT — application supplies explicit ID per reserved-ID doctrine |
| `project_key` | varchar(64) | Short machine key, unique per node (e.g. `lupopedia-core`) |
| `project_name` | varchar(255) | Human display name |
| `project_slug` | varchar(255) | URL-safe slug |
| `channel_id` | bigint | The one channel this project lives on |
| `orchestrator_id` | bigint | `actor_id` of the responsible orchestrator (human or agent) |
| `federation_node_id` | bigint | The one node this project belongs to |
| `status` | varchar(32) | `active`, `archived`, `paused` |
| `project_type` | varchar(64) | `core`, `web`, `cli`, `external`, `general` |
| `metadata_json` | json | Arbitrary project metadata |

**No foreign keys** — per doctrine. All relationships enforced at application layer.

**Timestamps** — all `bigint` in `YYYYMMDDHHIISS` UTC format per doctrine. No `DATETIME` or `TIMESTAMP`.
