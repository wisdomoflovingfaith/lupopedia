## 1) Current State Map

| Entrypoint | Config Loaded | Order / Logic |
| :--- | :--- | :--- |
| **index.php** | `lupopedia-config.php` | Primary. Redirects to `install.php` if missing. No legacy fallback. |
| **admin.php** | `lupopedia-config.php` | Primary. |
| **install.php** | `lupopedia-config.php` | Checks for existence to determine "Installed" state. |
| **install.php** | `config.php` | Detects presence for "Upgrade from Crafty Syntax" mode. |
| **remote-index.php** | `lupopedia-config.php` → `config.php` | Fallback logic: checks for Lupopedia config first, then legacy. |
| **my-channel.php** | `lupopedia-config.php` → `config.php` | Fallback logic similar to `remote-index.php`. |
| **CLI / Cron** | `lupopedia-config.php` | Explicitly required via `__DIR__ . '/../lupopedia-config.php'`. |

## 2) File Role Summary

### `config.php` (LEGACY)
*   **Role**: Legacy Crafty Syntax 3.7.5 configuration.
*   **Content**: Procedural variables (`$server`, `$database`, etc.).
*   **Current Use**: Only required for detecting existing installs during the upgrade wizard. Some poorly refactored legacy scripts still use it as a fallback.
*   **Risk**: Low, but causes confusion about source of truth.

### `lupopedia-config.php` (ACTIVE CANONICAL)
*   **Role**: Primary configuration for Lupopedia 4.0.x.
*   **Content**: Constant-based (`DB_*`, `LUPO_*_DIR`). Includes `lupo-includes/bootstrap.php`.
*   **Generated By**: `install.php`.
*   **Current Use**: The root of the runtime. Everything depends on it.

### `lupo-config.php` (ORPHAN/PROPOSAL)
*   **Role**: Orphaned draft or experimental configuration.
*   **Content**: Global arrays (`$GLOBALS['lupo_db_config']`). Copyright 2023.
*   **Current Use**: **None**. No files in the repository include or reference this file.
*   **Conflict**: Redundant with `lupopedia-config.php`.

### `config/` (ACTIVE SUPPLEMENTARY)
*   **Role**: Supplementary configuration files and metadata.
*   **Contents**:
    *   `global_atoms.yaml`: **CRITICAL**. Single source of truth for versioning (`GLOBAL_CURRENT_LUPOPEDIA_VERSION`).
    *   `constants.php`: Architect identity constants.
    *   `lupopedia.php`: Bridge/adapter for Laravel or external app usage.
    *   `GLOBAL_IMPORTANT_ATOMS.yaml`: Foundation atoms.
*   **Status**: Active and required for system boot (via `AtomLoader`).

### `lupo-config/` (PLANNED)
*   **Status**: Does not currently exist.

## 3) Consolidation Proposal

To align with the **Lupo-Prefix Doctrine** and reduce configuration sprawl, we recommend the following model:

### A) Canonical Entrypoint: `lupopedia-config.php`
*   Retain `lupopedia-config.php` as the primary user-facing root config (equivalent to `wp-config.php`).
*   **Logic Change**: Modify it to explicitly delegate core sections to the `lupo-config/` directory.

### B) Canonical Folder: `lupo-config/`
*   Rename `config/` directory to `lupo-config/`.
*   This directory will contain all modular configuration (atoms, identity, bridges).

### C) Conflict Resolution & Cleanup
1.  **Archive `config.php`**: Rename to `config.php.legacy`. Modify `install.php` to look for the renamed version if needed for upgrade detection, or better, move its data to a `legacy/` state flag.
2.  **Delete `lupo-config.php`**: This file is unused and misleading.
3.  **Consolidate Modular Files**:
    *   `lupo-config/mysql.php` (Extracted from `lupopedia-config.php`)
    *   `lupo-config/paths.php` (Extracted from `lupopedia-config.php`)
    *   `lupo-config/atoms.yaml` (Renamed from `global_atoms.yaml`)
    *   `lupo-config/identity.php` (Renamed from `constants.php`)

### D) Migration Plan

| Step | Action | Risk |

## 4) Compatibility Constraints

*   **Installer**: Must be updated to look for `config.php.legacy` during upgrade check.
*   **Fallback Database**: The upcoming file-based database system (`lupo-database/`) depends on `LUPO_DATABASE_DIR` defined in `lupopedia-config.php`. This must remain stable.
*   **Atoms**: Versioning is hard-linked to `config/global_atoms.yaml` via `lupo-includes/version.php`. This link must be updated to `lupo-config/global_atoms.yaml`.
*   **No PHP 8+ Syntax**: All changes must remain PHP 5.3 compliant.
