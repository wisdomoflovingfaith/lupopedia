# 🌬️ WINDSURF IDE DIRECTIVE: Actor Directory & Database Synchronization (v4.0.48)

**Captain's Mission:** Windsurf, you are tasked with finalizing the bridge between our filesystem-first **Actor Directory** and the **Lupopedia Database**. We are moving toward a "Portable Identity Capsule" model where an actor can be fully reconstructed from their directory.

## 🎯 Primary Objectives

### 1. 🏗️ Database Migration & Schema Alignment
- **Scan TOON Files**: Review all 216 TOON files in `lupo-database/lupopedia/toon/`, focusing on the 6 new tables added for 4.0.48:
  - `lupo_actor_history`, `lupo_actor_relationship_rules`, `lupo_capability_usage`, `lupo_llm_performance`, `lupo_federated_trust`, `lupo_session_recovery`.
- **Generate Migration SQL**: Create `lupo-database/migrations/migration_4.0.48_actor_identity_capsule.sql`.
  - Include `CREATE TABLE` statements for any missing tables found in TOONs.
  - Add missing columns to `lupo_actors`: `actor_root_path` (VARCHAR), `who_json_sync_status` (VARCHAR), `last_sync_ymdhis` (BIGINT).
  - Ensure **STRICT DOCTRINE COMPLIANCE**:
    - No Foreign Keys, No Triggers, No Defaults for Timestamps (all set in PHP).
    - BigInt UTC Timestamps (`YYYYMMDDHHIISS`).
    - Specify all columns in inserts.
    - PostgreSQL/MySQL/MariaDB compatibility.

### 2. 🎡 Update Installation Script (`lupo-database/migrations/install_new_lupopedia.sql`)
- Update the master installation script to include all new 4.0.48 tables and structure.
- **Enhanced Seeding Logic (Filesystem-to-Database Mapping)**:
  - The installer must now seed the database using files from the `lupo-actors/` directory as the source of truth for all default actors (IDs 0-10420).
  - **Human vs. Agent Logic**:
    - If `WHO.json` specifies `identity: human`, insert into `lupo_actors` AND `lupo_auth_users`.
    - If `WHO.json` specifies `identity: agent`, insert into `lupo_actors` AND `lupo_agents`.
  - **Seeding Actor 10000 (Captain Wolfie)**:
    - **Actor Table**: Name: `Eric Robin Gerdes`, Slug: `root-captain-10000`.
    - **Auth User Table**: Email: `wisdomoflovingfaith@gmail.com`, Provider: `google`, Display Name: `Wolfie`.
    - **History Table**: Populate from `lupo-actors/10000/history/resume.json` "best_work" entries.
  - **Customizable Identity**: Default values in the SQL should be based on these files, but the installation wizard (PHP) must be able to overwrite these values if the admin performing the install provides a different identity for the system root.

### 3. 🔄 Bidirectional Sync Script (`lupo-scripts/sync_actors_to_db.php`)
- Create a PHP script (5.3 compatible) that:
  - Reads an actor's directory (`lupo-actors/<id>/`).
  - Transfers `WHO.json` data to `lupo_actors.metadata_json`.
  - Transfers `history/resume.json` "best_work" entries to `lupo_actor_history` table.
  - Updates `last_sync_ymdhis` in the DB.
  - **Doctrine Check**: Ensure all database interaction uses `DatabaseFactory::getConnection()` and prepared statements.

### 4. 🗃️ Identity Capsule Portability
- Update `lupo-scripts/export_actor.sh` and `lupo-scripts/import_actor.sh` (previously stubs) to support full ZIP/TAR portability of an actor's directory, including a checksum validation against the database records.
