# 02. Data Model (The Skeleton) - 4.0.93

## **LILITH "Source of Truth" Protocol**

**Toon Files (Read-Only Senses)**: The `.json` files in `lupo-database/lupopedia/json/` are **READ-ONLY** artifacts generated by `generate_toon_files.py`. They serve only to provide the IDE with a reflection of the existing schema. **NEVER manually edit these files.**

**Installation DNA**: All schema changes must be performed in the `lupopedia/mysql/seed/` and `install_new_lupopedia` scripts.

## 📋 **Core Data Structure (From Toon JSON Analysis)**

### **lupo_contexts (Primary Knowledge Storage)**
```sql
CREATE TABLE lupo_contexts (
  context_id bigint NOT NULL,                    -- 63-bit Signed-Safe Integer
  context_code varchar(16) NOT NULL,              -- Unique context identifier
  context_name varchar(255) NOT NULL,             -- Human-readable name
  context_description text,                       -- Detailed description
  parent_context_id bigint,                       -- Hierarchical relationships
  is_system tinyint NOT NULL DEFAULT 0,           -- System vs user contexts
  is_fiction tinyint NOT NULL DEFAULT 0,          -- Fiction vs truth contexts
  is_installation_local tinyint NOT NULL DEFAULT 0, -- Installation-specific
  sort_order int NOT NULL DEFAULT 0,              -- Display ordering
  created_ymdhis bigint NOT NULL DEFAULT 0,       -- UTC timestamp (YYYYMMDDHHIISS)
  updated_ymdhis bigint NOT NULL,                 -- UTC timestamp
  weight_score decimal(5,2) NOT NULL DEFAULT 0.00, -- Semantic weight
  is_active tinyint NOT NULL DEFAULT 1,           -- Active status
  metadata_json json                              -- Flexible metadata
);
```

### **lupo_truth_questions (Question Management)**
```sql
CREATE TABLE lupo_truth_questions (
  truth_question_id bigint NOT NULL,              -- 63-bit Signed-Safe Integer
  parent_question_id bigint,                      -- Question hierarchy
  root_question_id bigint,                        -- Root question reference
  depth tinyint NOT NULL DEFAULT 0,                -- Question depth
  target_object_type varchar(64) NOT NULL,        -- What the question targets
  target_object_id bigint NOT NULL,               -- Target object ID
  question_text text NOT NULL,                    -- Full question text
  question_summary varchar(500),                  -- Brief summary
  asked_by_actor_id bigint NOT NULL,              -- Who asked
  asked_in_channel_id bigint,                     -- Channel context
  asked_in_thread_id bigint,                       -- Thread context
  asked_in_session_id varchar(128),               -- Session context
  question_status varchar(32) NOT NULL DEFAULT 'open', -- Status
  is_answered tinyint NOT NULL DEFAULT 0,         -- Answered flag
  is_featured tinyint NOT NULL DEFAULT 0,         -- Featured flag
  view_count bigint NOT NULL DEFAULT 0,            -- View statistics
  answer_count bigint NOT NULL DEFAULT 0,         -- Answer count
  follower_count bigint NOT NULL DEFAULT 0,       -- Follower count
  created_ymdhis bigint NOT NULL,                 -- Creation timestamp
  updated_ymdhis bigint NOT NULL,                 -- Update timestamp
  answered_ymdhis bigint,                         -- Answer timestamp
  closed_ymdhis bigint,                           -- Close timestamp
  is_deleted tinyint NOT NULL DEFAULT 0,          -- Soft delete
  deleted_ymdhis bigint,                          -- Delete timestamp
  metadata_json json                              -- Flexible metadata
);
```

CREATE TABLE lupo_truth_answers (

### **lupo_votes (Universal Voting System)**
```sql
CREATE TABLE lupo_votes (
  vote_id bigint NOT NULL,                         -- 63-bit Signed-Safe Integer
  target_type varchar(64) NOT NULL,                -- 'content', 'truth_question', 'truth_answer', 'comment'
  target_id bigint NOT NULL,                       -- Target object ID
  vote_type varchar(32) NOT NULL,                  -- 'like', 'dislike', 'helpful', 'not_helpful', 'insightful', 'confusing', 'flag'
  vote_value tinyint NOT NULL DEFAULT 1,           -- Vote value
  cast_by_actor_id bigint NOT NULL,                  -- Who voted
  cast_in_channel_id bigint,                       -- Channel context
  cast_in_thread_id bigint,                        -- Thread context
  reason_text varchar(500),                         -- Optional reason for downvotes/flags
  reason_code varchar(64),                          -- Coded reason ('outdated', 'incorrect', 'unclear', 'off_topic')
  is_current tinyint NOT NULL DEFAULT 1,            -- Allow vote changes (1 = current vote, 0 = superseded)
  created_ymdhis bigint NOT NULL,                 -- Creation timestamp
  updated_ymdhis bigint NOT NULL,                 -- Update timestamp
  is_deleted tinyint NOT NULL DEFAULT 0,          -- Soft delete
  deleted_ymdhis bigint,                           -- Delete timestamp
  PRIMARY KEY (vote_id)
);
```

## 🚨 **CRITICAL: 4.0.93 Doctrine Constraints**

### **Forbidden Constructs (STRICTLY ENFORCED)**
- ❌ **AUTO_INCREMENT**: All IDs must be generated by `IdGenerator::generate()`
- ❌ **TIMESTAMP fields**: Use `bigint` with UTC format (YYYYMMDDHHIISS)
- ❌ **FOREIGN KEYS**: Application-managed relationships only
- ❌ **TRIGGERS**: Application-level logic only
- ❌ **UNSIGNED integers**: Use signed 63-bit safe integers

### **Required ID Format**
- **All IDs**: `bigint` (63-bit signed-safe integers)
- **Generation**: `Lupo_Id_Generator::generate()`
- **Range**: -9,223,372,036,854,775,808 to 9,223,372,036,854,775,807

### **Timestamp Format**
- **Format**: `bigint` UTC timestamp
- **Pattern**: YYYYMMDDHHIISS (20260330140000)
- **Timezone**: UTC only
- **No quotes in database, quotes in YAML**

## 🏗️ **Architectural Evolution**

### **DELETED: Monolithic lupo_truth_knowledge**
The old monolithic `lupo_truth_knowledge` table has been **completely removed** and replaced with:

1. **lupo_truth_questions** - Question management
2. **lupo_truth_answers** - Answer management  
3. **lupo_votes** - Universal voting system
4. **lupo_truth_evidence** - Evidence tracking
5. **lupo_truth_followers** - Question following
6. **lupo_truth_context_map** - Context relationships

### **Split Relational Architecture**
- **Questions**: Standalone with hierarchical relationships
- **Answers**: Linked to questions with voting and confidence
