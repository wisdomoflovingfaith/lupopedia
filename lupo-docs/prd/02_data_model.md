# 02. Data Model (The Skeleton) - 4.0.93

## **LILITH "Source of Truth" Protocol**

**Toon Files (Read-Only Senses)**: The `.json` files in `lupo-database/lupopedia/json/` are **READ-ONLY** artifacts generated by `generate_toon_files.py`. They serve only to provide the IDE with a reflection of the existing schema. **NEVER manually edit these files.**

**Installation DNA (4.0.x):** Canonical schema is **`lupo-database/lupopedia/mysql/install/install_new_lupopedia.sql`** (plus seed under `mysql/seed/` and Crafty import **`import_from_old_crafty_syntax.sql`** when applicable). There is **no** Lupopedia→Lupopedia migration chain: update install SQL, then **fresh install**. See constitutional **PRD 00 §1.0** and root **README.md**.

CREATE TABLE lupo_contexts (

### **lupo_votes (Universal Voting System)**
```sql
CREATE TABLE lupo_votes (
  vote_id bigint NOT NULL,                         -- 63-bit Signed-Safe Integer
  target_type varchar(64) NOT NULL,                -- Polymorphic target (what is being voted on?)
  -- Valid values: content, truth_question, truth_answer, truth_evidence,
  --              channel, thread, context, context_card, collection, 
  --              collection_tab, comment, actor, edge
  target_id bigint NOT NULL,                       -- Target object ID
  vote_type varchar(32) NOT NULL,                  -- like, dislike, helpful, not_helpful, insightful, confusing, flag, agree, disagree
  vote_value tinyint NOT NULL DEFAULT 1,           -- Vote value
  cast_by_actor_id bigint NOT NULL,                  -- Who voted
  cast_in_channel_id bigint,                       -- Channel context
  cast_in_thread_id bigint,                        -- Thread context
  reason_text varchar(500),                         -- Optional reason for downvotes/flags
  reason_code varchar(64),                          -- Coded reason ('outdated', 'incorrect', 'unclear', 'off_topic')
  is_current tinyint NOT NULL DEFAULT 1,            -- Allow vote changes (1 = current vote, 0 = superseded)
  created_ymdhis bigint NOT NULL,                 -- Creation timestamp
  updated_ymdhis bigint NOT NULL,                 -- Update timestamp
  is_deleted tinyint NOT NULL DEFAULT 0,          -- Soft delete
  deleted_ymdhis bigint,                           -- Delete timestamp
  PRIMARY KEY (vote_id)
);

-- Indexes
CREATE UNIQUE INDEX lupo_votes_unq_actor_target ON lupo_votes (cast_by_actor_id, target_type, target_id, is_current);
CREATE INDEX lupo_votes_idx_target ON lupo_votes (target_type, target_id);
CREATE INDEX lupo_votes_idx_vote_type ON lupo_votes (vote_type, vote_value);
CREATE INDEX lupo_votes_idx_actor ON lupo_votes (cast_by_actor_id);
CREATE INDEX lupo_votes_idx_channel ON lupo_votes (cast_in_channel_id);
CREATE INDEX lupo_votes_idx_thread ON lupo_votes (cast_in_thread_id);
CREATE INDEX lupo_votes_idx_created ON lupo_votes (created_ymdhis);
CREATE INDEX lupo_votes_idx_current ON lupo_votes (is_current);
CREATE INDEX lupo_votes_idx_deleted ON lupo_votes (is_deleted);
```

## 🚨 **CRITICAL: 4.0.93 Doctrine Constraints**

### **Forbidden Constructs (STRICTLY ENFORCED)**
- ❌ **AUTO_INCREMENT**: All IDs must be generated by `IdGenerator::generate()`
- ❌ **TIMESTAMP fields**: Use `bigint` with UTC format (YYYYMMDDHHIISS)
- ❌ **FOREIGN KEYS**: Application-managed relationships only
- ❌ **TRIGGERS**: Application-level logic only
- ❌ **UNSIGNED integers**: Use signed 63-bit safe integers

### **Required ID Format**
- **All IDs**: `bigint` (63-bit signed-safe integers)
- **Generation**: `Lupo_Id_Generator::generate()`
- **Range**: -9,223,372,036,854,775,808 to 9,223,372,036,854,775,807

### **Timestamp Format**
- **Format**: `bigint` UTC timestamp
- **Pattern**: YYYYMMDDHHIISS (20260330140000)
- **Timezone**: UTC only
- **No quotes in database, quotes in YAML**

## 🏗️ **Architectural Evolution**

### **DELETED: Monolithic lupo_truth_knowledge**
The old monolithic `lupo_truth_knowledge` table has been **completely removed** and replaced with:

1. **lupo_truth_questions** - Question management
2. **lupo_truth_answers** - Answer management  
3. **lupo_votes** - Universal voting system
4. **lupo_truth_evidence** - Evidence tracking
5. **lupo_truth_followers** - Question following
6. **lupo_truth_context_map** - Context relationships

### **Split Relational Architecture**
- **Questions**: Standalone with hierarchical relationships
- **Answers**: Linked to questions with voting and confidence
