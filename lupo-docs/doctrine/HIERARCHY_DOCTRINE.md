# Lupopedia Content Overwrite Hierarchy

To ensure predictable content resolution and synchronization across environments (IDE filesystem, database, and TOON exports), Lupopedia enforces a strict overwrite hierarchy.

## 1. Hierarchy Levels

| Priority | Source | Description |
| :--- | :--- | :--- |
| **P0 (Highest)** | **FILESYSTEM** | Files in `lupo-channels/`. Treats the IDE as the primary source of truth. |
| **P1** | **DATABASE** | Live state in SQL tables. Overridden by Filesystem if a file exists. |
| **P2 (Lowest)** | **SEED / TOONS** | Files in `lupo-database/csv_data/` or `lupo-docs/toons/`. Used for initial setup. |

## 2. Load Order Logic

When a system component (e.g., `lupo-channels` controller or `MdImporter`) resolves a piece of content:

1.  **Check Filesystem**: It first checks `LUPO_CHANNEL_DIR` (`lupo-channels/`) for a corresponding `.md` file.
2.  **Filesystem Found**: If found, the file content and its **FLARE headers** are used as the result. Any differing data in the database is ignored (though a background sync may update the DB to match).
3.  **Filesystem Missing**: If no file exists, the system queries the **Database** (`lupo_dialog_messages`, `lupo_contents`, etc.).
4.  **Database Empty**: If the database has no record, the system looks for **Seed Data** or **TOONs** as a final fallback (typically only during installation or re-import).

## 3. Synchronization Protocols

### DB → CSV/TOON (Export)
The database state is exported to CSV and TOON files when running `lupo-scripts/generate_toon_files.py`. This ensures that the documentation and seed files reflect the current live state.

### FILESYSTEM → DB (Import)
Standalone files in `lupo-channels/` are imported into the database:
- **On Boot**: Core systems (like ANUBIS or the Installer) scan for new files.
- **On Demand**: Running `lupo-scripts/import_channels_and_artifacts.py` forces a sync from filesystem to DB.

## 4. Configuration

The canonical path for the filesystem source is defined in `lupopedia-config.php`:

```php
define('LUPO_CHANNEL_DIR', LUPO_PREFIX . 'channels'); // Resolves to 'lupo-channels'
```
