# 4.0.17 Diagnostics and Compatibility Notes

**Status:** Permanent.  
**Audience:** Contributors, QA, and agents.  
**Purpose:** Document Android/Messenger behavior and Crafty Syntax 3.7.5 compatibility for 4.0.17 validation and support.

---

## Android / Messenger Behavior

- **Share targets and OEM stubs:** On Android, share intents and Messenger-style flows may use OEM-specific stubs or system webviews. Behavior can differ from desktop Chrome.
- **Chrome / WebView fallback:** When testing from mobile or in-app browsers, use Chrome or the system WebView as the primary test target; document any OEM-specific deviations.

---

## Crafty Syntax 3.7.5 Compatibility

- Crafty Syntax 3.7.5 uses **old-school HTML and JavaScript** (no SPA framework). It behaves like a **pure web app**: full page loads, form posts, and traditional JS where applicable.
- For Lupopedia migration and validation: the installer and wizard assume a clean Crafty 3.7.5 baseline. Messenger and other clients that present a “clean terminal” (minimal JS, standard form behavior) align with this baseline.

---
