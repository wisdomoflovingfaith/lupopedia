## Critical Path Forward

The **database-first principle** is the core of 4.0.21:

> "Headers are projections, not sources. The database is canonical truth."

### Generator as Bridge
`generate_headers.py` is the only component that should write headers. It translates database state into filesystem projections.

### Content Loader as Guardian
`import_os.py` and `content-controller.php` must:
- Never update DB from headers
- Always validate headers against DB
- Warn loudly when drift occurs

### Doctrine as Conscience
All documentation must emphasize that manual header edits will be overwritten and are not supported after 4.0.21.
