## INDEX SCHEMA

Each entry contains:

**Core Fields:**
- `file_path_from_root` - Evidence path (string)
- `header_present` - Boolean
- `footer_present` - Boolean

**Header Fields:**
- `actor_id` - Actor identity (integer)
- `lupo_agent` - Agent key (string)
- `x_lupo_forwarded` - Forwarding chain (string)
- `channel_id` - Channel assignment (integer)
- `system_version` - Version tag (string)
- `purpose` - File purpose (string)
- `mood_rgb` - Mood color (string)
- `last_modified` - UTC YYYYMMDD (string)

**Footer Fields:**
- `referenced_by_files` - File references (array)
- `referenced_by_channels` - Channel references (array)
- `referenced_by_actors` - Actor references (array)
- `inbound_edges` - Semantic edges (array)
- `footnotes` - Additional notes (array)
- `version` - Footer version (string)
- `last_verified` - UTC YYYYMMDD (string)
- `last_verified_by` - Verifier agent (string)

## USAGE EXAMPLES

### Query by Actor ID

```bash
# View all files by actor 1001
cat docs/index/by_actor/1001.json | jq '.entries[] | .file_path_from_root'

# Count files per actor
cat docs/index/flip_index.json | jq '.entries | group_by(.actor_id) | map({actor_id: .[0].actor_id, count: length})'
```

### Query by Channel

```bash
# View all files in channel 42
cat docs/index/by_channel/42.json | jq '.entries[] | .file_path_from_root'

# List all channels
cat docs/index/flip_index.json | jq '[.entries[].channel_id] | unique'
```

### Query by X_LUPO_FORWARDED

```bash
# View all files with x_lupo_forwarded = "1001:10000"
cat docs/index/by_forward/1001_10000.json | jq '.entries[] | .file_path_from_root'

# List all forwarding pairs
ls docs/index/by_forward/ | sed 's/_/:/' | sed 's/.json//'
```

### Find Orphans

```bash
# View all files missing footers
cat docs/index/orphans.json | jq '.orphans[] | select(.issue == "missing_footer") | .file_path'

# View all files missing headers
cat docs/index/orphans.json | jq '.orphans[] | select(.issue == "missing_header") | .file_path'

# Count orphans by issue type
cat docs/index/orphans.json | jq '.orphans | group_by(.issue) | map({issue: .[0].issue, count: length})'
```

### Latest Activity by Actor

```bash
# Find latest activity for each actor
cat docs/index/flip_index.json | jq '.entries | group_by(.actor_id) | map({actor_id: .[0].actor_id, latest: (map(.last_modified) | max)})'

# Find most active actor
cat docs/index/flip_index.json | jq '.entries | group_by(.actor_id) | map({actor_id: .[0].actor_id, count: length}) | sort_by(.count) | reverse | .[0]'
```

### Search by Purpose

```bash
# Find all files with specific purpose keyword
cat docs/index/flip_index.json | jq '.entries[] | select(.purpose | contains("registry")) | .file_path_from_root'
```

### Search by Inbound Edges

```bash
# Find all files with specific inbound edge
cat docs/index/flip_index.json | jq '.entries[] | select(.inbound_edges | contains(["header_lookup"])) | .file_path_from_root'
```
