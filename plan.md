# Root Plan

This file is the high-level strategic roadmap for the repository.

Detailed execution planning lives in:

- `lupo-docs/versions/4.1.4/TODO.md` (current 4.1.4 execution)
- `lupo-docs/versions/4.1.4/PLAN.md` (version-specific planning)
- Historical versions in `lupo-docs/versions/` archive

## Overall Strategy

Lupopedia is being developed through version-based, documentation-driven execution.

The strategic model is:

1. Define and stabilize systems through iterative releases (completed 4.0.x baseline).
2. Use version-scoped documentation as the planning and execution authority.
3. Use Softaculous review as the primary external feedback loop.
4. 4.1.4+ focus on production readiness, Crafty Syntax integration, and system hardening.

## Iterative Release Flow

1. 4.0.x series completed baseline stabilization.
2. 4.1.0-4.1.3 iterative development and header doctrine establishment.
3. 4.1.4 root documentation layer alignment and system hardening.
4. Current focus: Crafty Syntax integration and production readiness.
5. Future: 4.1.5+ feature completion and release hardening.

- Version plans carry the detailed sequencing.
- If priorities differ, version-scoped plans under `lupo-docs/versions/` are the execution authority.
