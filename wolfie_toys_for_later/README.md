# wolfie_toys_for_later

All new ideas after 2026-08-17 go here.

We work the PRD files we already have first. Do not mint a new PRD group for a new idea until Captain says the existing corpus is ready.

This folder is a parking lot. Not doctrine. Not KEY grammar. Not install SQL. Not a number assignment.

## What belongs here

- New product ideas
- New grammar proposals
- New widgets, protocols, and toys that are not already a file in `docs/prd/`

## What does not belong here

- Edits to existing PRDs (those stay in `docs/prd/`)
- Copilot/agent guesses at PRD numbers (validate against the folder; PRD 84 forbids reuse)
- HEX6 guesses
- LUP KEY changes

## File naming

```text
YYYYMMDDHHIISS_short_title.md
```

ASCII. One idea per file.
