# HEX2 HEX3 HEX4 HEX5 -- session conflict slang

Parked 20260817101000. Not a PRD. Not Color Identity. Not CLRLEX.

Wolfie uses these only while multiple actors are in a fight:

```text
HEX2 = two actors disagreeing     example: HEX2(LILITH, WOLFIE)
HEX3 = three actors disagreeing
HEX4 = four actors disagreeing
HEX5 = five actors disagreeing
```

They are semantic fights. They are not colors.

Never:

- stored
- registered
- displayed
- rendered
- mapped
- converted
- emitted
- included in POWERED_BY
- included in CLRLEX
- included in any PRD

Internal conflict slang, nothing more.

## Do not promote this into doctrine

PRD 90 already owns the public diagnostic word:

```text
HEX5 = MULTI_AGENT_CONFLICT
```

PRD 90 also says HEX5 does **not** mean "exactly five participating agents."

If a session needs a headcount, Wolfie may say HEX2(LILITH, WOLFIE) out loud. If the system must record a conflict, it records MULTI_AGENT_CONFLICT / HEX5 as PRD 90 defines it. Do not add HEX2-HEX4 columns, pages, or registry keys.

HEX6 remains the only color hex. HEX2-HEX5 are never truncated HEX6.
