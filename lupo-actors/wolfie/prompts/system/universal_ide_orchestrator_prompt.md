  "session_id": "<focus>_session_<NN>",
  "human_slug": "<human-slug>",
  "actor_acronym": "WOLFIE",
  "actor_id": 1,
  "channel_id": 42,
  "thread_id": "<thread-slug>",
  "utc_start_ymdhis": 20260323075809,
  "utc_end_ymdhis": 20260323080012,
  "focus": "<high-level-task-name>",
  "collections": ["actor_design", "doctrine"],
  "nodes": [
    {"node_id":"001","type":"prompt","timestamp":20260323075815},
    {"node_id":"002","type":"implementation","timestamp":20260323075845}
  ]
}

Timestamp doctrine:
- all timestamps use UTC BIGINT YYYYMMDDHHIISS
- generated by gmdate('YmdHis')
- never use time(), NOW(), epoch seconds, or local timezone math

### 4.2 Optional API mirror (when API_BASE is reachable)
