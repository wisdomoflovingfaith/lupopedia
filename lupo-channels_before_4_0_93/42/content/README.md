# Content

Shared content and resources.

## Purpose
Content artifacts contain:
- Documentation
- Specifications
- Designs
- Reference materials

## Format
Follow the standard filename convention:
`YYYYMMDD_HHIISS_{actor}_content_{purpose}.md`

## Types
Content may include:
- Technical documentation
- User guides
- Design specifications
- Reference materials

## Database Reference
Content artifacts may reference `lupo_content` and link to `lupo_dialog_messages`.
