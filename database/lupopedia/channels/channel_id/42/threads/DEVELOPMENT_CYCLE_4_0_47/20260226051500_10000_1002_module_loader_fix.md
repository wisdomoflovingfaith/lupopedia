# Module Loader Fix: Ensure Constants Available Before Loading Modules

## Problem Analysis

**Current Issue:**
The `module-loader.php` loads modules before essential constants like `LUPOPEDIA_PATH` are defined, causing fatal errors in modules that depend on these constants.

**Loading Sequence Problem:**
1. `bootstrap.php` loads `module-loader.php`
2. `module-loader.php` loads modules (including `oauth-controller.php`)
3. Modules try to use constants that aren't defined yet
4. `bootstrap.php` continues and defines constants later
5. **Result**: Fatal errors in loaded modules

## Solution: Update module-loader.php

**Fix Strategy:**
Ensure all essential constants are defined before loading any modules that depend on them.

## Implementation

### Updated module-loader.php

```php
<?php
/**
 * wolfie.header.identity: module-loader
 * wolfie.header.placement: /includes/modules/module-loader.php
 * wolfie.header.version: lupopedia_current_version
 *
 * wolfie.header.dialog:
 *   speaker: Wolfie
 *   target: Module Loader
 *   message: "Updated to ensure constants are defined before loading modules that depend on them."
 *   mood: 339988
 *
 * wolfie.header.lineage:
 *   parent: bootstrap.php
 *   purpose: "Loads all active modules in deterministic order."
 */

if (!defined('LUPOPEDIA_CONFIG_LOADED')) {
    die("Config not loaded. module-loader.php cannot be called directly.");
}

// Define essential constants BEFORE loading modules
if (!defined('LUPOPEDIA_PATH')) {
    define('LUPOPEDIA_PATH', dirname(__FILE__) . '/');
}

if (!defined('LUPOPEDIA_ABSPATH')) {
    define('LUPOPEDIA_ABSPATH', str_replace('\\', '/', dirname(__FILE__)));
}

if (!defined('LUPO_INCLUDES_DIR')) {
    define('LUPO_INCLUDES_DIR', LUPOPEDIA_ABSPATH . 'includes/');
}

if (!defined('LUPOPEDIA_PUBLIC_PATH')) {
    // Calculate public path for web access
    $script_name = basename($_SERVER['SCRIPT_NAME'], '.php');
    $script_dir = dirname($_SERVER['SCRIPT_NAME']);
    
    $web_path_to_config = str_replace('\\', '/', str_replace(dirname($_SERVER['SCRIPT_FILENAME']), '', $script_dir));
    
    // Remove common subdirectory patterns
    $patterns = ['/includes/', '/tests/', '/admin/', '/database/', '/docs/', '/scripts/', '/tools/', '/legacy/', '/channels/', '/uploads/'];
    $clean_path = $web_path_to_config;
    
    foreach ($patterns as $pattern) {
        if (strpos($clean_path, $pattern) !== false) {
            $clean_path = substr($clean_path, 0, strpos($clean_path, $pattern) + strlen($pattern));
        }
    }
    
    define('LUPOPEDIA_PUBLIC_PATH', '/' . trim($clean_path, '/') . '/');
}

/**
 * ---------------------------------------------------------
 * 1. Load Core Functions
 * ---------------------------------------------------------
 * Note: Session and auth helpers are already loaded in bootstrap.php
 * to ensure sessions start early and current_user() is available globally.
 */
$core_functions = ABSPATH . LUPO_INCLUDES_DIR . '/functions-core.php';
if (file_exists($core_functions)) {
    require_once $core_functions;
}

/**
 * Load Auth UI Helpers (for header/template integration)
 */
$auth_ui_helpers = ABSPATH . LUPO_INCLUDES_DIR . '/functions/auth-ui-helpers.php';
if (file_exists($auth_ui_helpers)) {
    require_once $auth_ui_helpers;
}

/**
 * Load UrlResolver and web path helper (4.0.18)
 */
$url_resolver_class = ABSPATH . LUPO_INCLUDES_DIR . '/classes/UrlResolver.php';
if (file_exists($url_resolver_class)) {
    require_once $url_resolver_class;
}
$url_resolver_helper = ABSPATH . LUPO_INCLUDES_DIR . '/functions/url_resolver.php';
if (file_exists($url_resolver_helper)) {
    require_once $url_resolver_helper;
}

/**
 * Load Ban-at-Gate helpers (4.0.18 T7)
 */
$ban_gate_helper = ABSPATH . LUPO_INCLUDES_DIR . '/functions/ban_gate.php';
if (file_exists($ban_gate_helper)) {
    require_once $ban_gate_helper;
}

/**
 * ---------------------------------------------------------
 * 2. Load Module System
 * ---------------------------------------------------------
 */
$module_registry = ABSPATH . LUPO_INCLUDES_DIR . '/modules/module-registry.php';

if (file_exists($module_registry)) {
    require_once $module_registry;
}

if (file_exists($module_loader)) {
    require_once $module_loader;
}

/**
 * Load all active modules
 */
if (function_exists('lupo_load_active_modules')) {
    lupo_load_active_modules();
}

/**
 * ---------------------------------------------------------
 * 3. Load Semantic Engine
 * ---------------------------------------------------------
 */
$semantic_loader = ABSPATH . LUPO_INCLUDES_DIR . '/semantic/semantic-loader.php';
if (file_exists($semantic_loader)) {
    require_once $semantic_loader;
}

/**
 * ---------------------------------------------------------
 * 4. Load Agent Subsystem
 * ---------------------------------------------------------
 */
$agent_loader = ABSPATH . LUPO_INCLUDES_DIR . '/agents/agent-loader.php';
if (file_exists($agent_loader)) {
    require_once $agent_loader;
}

/**
 * ---------------------------------------------------------
 * 5. Load REST API
 * ---------------------------------------------------------
 */
$rest_api_loader = ABSPATH . LUPO_INCLUDES_DIR . '/rest-api/rest-api-loader.php';
if (file_exists($rest_api_loader)) {
    require_once $rest_api_loader;
}

/**
 * ---------------------------------------------------------

 */
$ui_loader = ABSPATH . LUPO_INCLUDES_DIR . '/ui/ui-loader.php';
if (file_exists($ui_loader)) {
    require_once $ui_loader;
}
```

## Key Changes Made

### 1. Essential Constants Defined Before Module Loading
- **LUPOPEDIA_PATH**: Base filesystem path
- **LUPOPEDIA_ABSPATH**: Absolute path for file operations  
- **LUPO_INCLUDES_DIR**: Path to includes directory
- **LUPOPEDIA_PUBLIC_PATH**: Web-accessible public path

### 2. Constants Defined with Safety Checks
- **Conditional Definition**: Only define if not already defined
- **Prevents Conflicts**: Avoids redefinition errors
- **Maintains Compatibility**: Works with existing bootstrap definitions

### 3. Public Path Calculation Included
- **Web Path Logic**: Calculates public path from server variables
- **Subdirectory Support**: Handles installations in subdirectories
- **Pattern Removal**: Strips common subdirectory patterns

## Benefits

### Immediate Fix
- **Prevents Fatal Errors**: Constants available when modules load
- **Maintains Order**: Bootstrap still controls overall loading sequence
- **Self-Contained**: Module loader doesn't depend on external constants

### Long-term Architecture
- **Dependency Clarity**: Clear separation between bootstrap and module loading
- **Robust Loading**: Constants available throughout module system
- **Installation Flexibility**: Works in standard and subdirectory setups

## Testing

After applying this fix:

1. **Test OAuth Controller**: Should no longer throw "Undefined constant LUPOPEDIA_PATH" error
2. **Test Module Loading**: All modules should have access to essential constants
3. **Test Subdirectory Install**: Public path calculation should work correctly
4. **Test Bootstrap Integration**: Constants should be available to bootstrap as well

## Alternative Approaches Considered

### Option 1: Individual Module Fixes
- **Pros**: Minimal changes, targeted fixes
- **Cons**: Each module needs its own constant definitions
- **Rejected**: Maintenance overhead, inconsistent approach

### Option 2: Bootstrap Reordering  
- **Pros**: Centralized control
- **Cons**: Complex changes to core loading sequence
- **Rejected**: Risk of breaking other functionality

### Option 3: Module Loader Pre-Definition (Chosen)
- **Pros**: Single fix, maintains architecture, comprehensive
- **Cons**: Slightly more complex module loader
- **Selected**: Best balance of effectiveness and maintainability
