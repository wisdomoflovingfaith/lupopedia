# Registry Schema Diagnosis - Lupopedia 4.0.27
**Date**: 2026-02-22  
**Issue**: Column 'registry_id' not found errors during installation  
**Root Cause**: Schema definition vs seed data mismatch

## THE PROBLEM

### What's Happening
Installation fails with error:
```
SQLSTATE[42S22]: Column not found: 1054 Unknown column 'registry_id' in 'field list'
```

### Root Cause
The `lupo_registry` table definition in `install_new_lupopedia.sql` (lines 3631-3650) does NOT include a column named `registry_id`:

```sql
CREATE TABLE lupo_registry (
  registry_id bigint NOT NULL AUTO_INCREMENT,  -- PRIMARY KEY, AUTO_INCREMENT
  entity_type varchar(50) NOT NULL,
  entity_index_id bigint NOT NULL DEFAULT 0,
  entity_index bigint NOT NULL DEFAULT 0,
  federation_node_id bigint NOT NULL DEFAULT 0,
  reserved_ymdhis bigint NOT NULL DEFAULT 0,
  metadata text,
  entity_key varchar(255) DEFAULT NULL,
  entity_name varchar(255) DEFAULT NULL,
  entity_table varchar(255) DEFAULT NULL,
  created_ymdhis bigint NOT NULL DEFAULT 0,
  updated_ymdhis bigint NOT NULL DEFAULT 0,
  is_deleted tinyint NOT NULL DEFAULT 0,
  deleted_ymdhis bigint DEFAULT NULL,
  is_active tinyint NOT NULL DEFAULT 1,
  is_kernel tinyint NOT NULL DEFAULT 0,
  metadata_json text,
  PRIMARY KEY (registry_id)
);
```

**NO `registry_id` column exists!**

### But Files Try To Use It
Many seed files attempt to INSERT with `registry_id`:
- `seed_lupopedia.sql` - 100+ INSERT statements
- `install_new_lupopedia.sql` (lines 3805+) - Broken seed data embedded in schema file
- Various migration scripts

## THE SOLUTION

### 1. ✅ Fixed: seed_minimal_4.0.26.sql
**Removed registry INSERT statements entirely**
- Reason: `registry_id` is AUTO_INCREMENT
- Registry entries auto-generated by application code
- No manual seeding needed for minimal bootstrap

### 2. ✅ Fixed: install_new_lupopedia.sql  
**Commented out ALL embedded seed data** (line 3799)
- Schema file should contain ONLY table definitions
- Seed data belongs in separate `seed_minimal_4.0.26.sql`
- Prevents schema/data mixing errors

### 3. ⚠️ NEEDS FIX: seed_lupopedia.sql
**Still contains 100+ broken registry INSERTs**
- Uses non-existent `registry_id` column
- This file is NOT used by minimal install
- Will be regenerated later from TOON files with correct schema
